# プロンプトの型と業務プロンプト集

`{ }` を自分の情報で埋めて使う。全て日本語出力を前提。

## 0. 基本型(全ての土台)

```
# 役割(ROLE)
あなたは〇〇の専門家です。

# 背景(CONTEXT)
- 目的:
- 読み手/対象:
- 制約条件(文字数・トーン・NG):
- 参考情報:

# タスク(TASK)
〇〇を作成してください。

# 出力形式(FORMAT)
- 形式: (箇条書き/表/見出し付き本文 など)
- 長さ:
- 言語: 日本語
```

コツ:
- CONTEXT を厚くするほど品質が上がる。
- 思考手順は指示しない(「step by step」は書かない)。
- 出力がずれたら FORMAT を具体化する。例を1つ貼るのが最も効く。

## 1. 議事録・要約・タスク化

最も時間回収が大きい用途。

### ① 議事録 → 要約&タスク
```
以下の議事メモを整理してください。
メモ: {貼り付け}
出力: ①要点要約(3点) ②決定事項 ③ToDo(担当者・期限付き表) ④未決定・要確認事項。
メモにない事柄は推測せず「記載なし」とする。日本語。
```

### ② 長文要約(字数指定)
```
次の文章を要約。句読点込み500字程度、重要な点を3つに絞り箇条書き。
文章: {貼り付け}
専門用語は可能な限り平易に言い換える。
```

### ③ 長文 → 構造化(見出し + 想定Q&A)
```
以下を「見出し+箇条書き」の構造に整理し、最後に想定Q&Aを5つ作る。
テキスト: {貼り付け}
```

ポイント: 「ロール設定・出力形式・定量条件」を入れるだけで修正回数が大幅に減る。

## 2. リサーチ・競合分析

推論モデルに Web 検索を許可して使う。**出典URLを必ず出させる。**

### ① 競合分析
```
「{業界/商品}」の主要競合5社を調査し、表で比較。
列: 会社/サービス名 | 価格 | 強み | 弱み | ターゲット | 差別化ポイント。
各行に出典URL。推測は「推測」と明記。日本語。
```

### ② ターゲット・ペルソナ
```
{商品}の想定顧客を3タイプに分けてペルソナ化。
各: 属性 / 抱える悩み / 購入の決め手 / 常用メディア / 刺さるメッセージ。
```

### ③ トレンド調査
```
「{テーマ}」に関する直近3ヶ月の最新トレンドをWeb検索して調査。
トップ5件を「何が新しいか / なぜ重要か / 出典URL / 日付」で。未確認情報は除外。
```

## 3. 出力改善(批評・複数案・役割設定)

一発で完成を狙わず、このループを回す。

### ① 成果物を批評させる
```
以下の{成果物}を、{対象読者}の視点で厳しく批評。
観点: 伝わりやすさ / 説得力 / 欠点 / 改善案。
最後に「最も効果の高い修正3つ」を優先順で。
成果物: {貼り付け}
```

### ② 複数案を出させて選ぶ
```
{タスク}を、方向性の異なる3案作成。
案A: 安全・王道 / 案B: 尖った挑戦的 / 案C: コンパクト。
各案の狙いとメリットを一言ずつ添える。
```

### ③ 役割(ペルソナ)を与える
```
あなたは{具体的な専門家: 例「販促歴10年のECマーケター」}。
その立場と経験則に基づいて、{依頼}に答えてください。
一般論ではなく、現場で使える具体策を。
```

## 4. メール・営業アウトリーチ

### ① コールドメール
```
# 背景
送り先: {役職/業種}、自社の提供価値: {一言}、ゴール: {15分の打合せ予約}。
# タスク
コールドメールを作成。
# 制約
120語以内、件名は6語以内、相手の具体的な課題から書き出す、CTAは1つだけ、
「お世話になっております」等の定型挨拶は使わない。日本語。
```

### ② フォローアップ(返信なし)
```
{日付}に送った{要件}のメールに返信がない相手へ、しつこくない再連絡を3パターン。
各80語以内。新しい価値(事例/資料)を1つ添えて、断りやすい逃げ道も用意する。
```

### ③ 議事録 → お礼&ネクストアクション
```
以下の打合せメモから、お礼メールを作成。
メモ: {貼り付け}
含める: 感謝 / 決定事項の確認3点 / こちらの次アクションと期限 / 相手への依頼。
日本語、200語以内。
```

## 5. セールスコピー・LP・広告

訴求は 1コピー = 1ベネフィットに絞る。

### ① 広告コピー(PAS型)
```
# 背景
商品: {商品名と特徴}、ターゲット: {誰}、訴求したい1番の価値: {ベネフィット}。
# タスク
Facebook/Instagram広告コピーを5案。各案: 痛みを提示→深掘り→解決→社会的証明→強いCTA。
# 制約
各125語以内、日本語、絵文字は1〜2個まで。
```

### ② LPファーストビュー
```
商品「{商品}」のLPファーストビューを作成。
出力: ①ヘッドライン3案 ②サブコピー ③CTAボタン文言3案。
各ヘッドラインは「結果/数字/反論処理」のいずれかの切り口で。誇大表現は避ける。
```

### ③ 商品説明(特徴 → ベネフィット変換)
```
以下の機能リストを、顧客のベネフィット言語に変換して箇条書きで。
機能: {箇条書き}
各行「機能 → だから あなたは〜できる」の形式。日本語。
```

出力後に「もっと具体の数字を入れて」で精度が上がる。

## 6. SNS・コンテンツ企画

### ① ネタを一気に30個出す
```
# 背景
アカウント: {ジャンル/商品}、ターゲット: {誰のどんな悩み}。
# タスク
保存されるショート動画のネタを30個。「逆説/失敗談/ビフォーアフター/意外な使い方」の4型を混ぜる。
# 出力形式
表: 番号 | 型 | タイトル案 | 最初の1秒フック。日本語。
```

### ② 最初の3秒フックを磨く
```
次の投稿テーマ「{テーマ}」について、スクロールを止める冒頭3秒のフックを10案。
各案に「なぜ止まるか」の理由を一言添える。煽りすぎず、具体の数字や問いを使う。
```

### ③ 30秒台本に展開
```
テーマ「{テーマ}」で30秒の縦型動画台本を作成。
構成: フック(3秒)→本題3ポイント→CTA。
各カットに「画面の指示」「ナレーション」を分けて記載。日本語、話し言葉。
```
