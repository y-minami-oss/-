### 沿革（主要）
- 1927年8月　神姫自動車株式会社設立（神港タクシーの木下栄が構想、神戸姫路電気鉄道が支援）
- 1943年5月　神姫合同自動車に商号変更、本社を姫路市へ
- 1956年5月　神姫自動車に商号復帰
- 1959年1月　神姫観光株式会社を設立し旅行業に参入
- 1972年5月　現商号「神姫バス株式会社」に変更
- 2006年　神戸市バス（落合・西神中央・南の3営業所）の運行管理を受託

出典: [Weblio](https://www.weblio.jp/content/%E7%A5%9E%E5%A7%AB%E3%83%90%E3%82%B9), [edinetdb 沿革](https://edinetdb.jp/company/E04160/history)

## 4. 中期経営計画（2025-2027、最終年度2028年3月期）

- 基本方針: 既存事業の強化／成長事業の開拓・拡大
- 重点戦略: ①既存事業の強化（路線バス軸の地域交通体系、ライフプラットフォーム、不動産賃貸）②成長事業の開拓・拡大（不動産開発参入、インバウンド、M&A）③人的資本経営
- 不動産を自動車運送に並ぶ「第二の柱」へ
- 数値目標（2027年度）: 売上高590億円／営業利益37億円／経常利益38億円／純利益25.7億円
- 投資計画: 3年で総額250億円（成長投資150・基盤強化30・維持更新70）。⚠ 日経は「戦略投資180億円」と報道しており区分が異なる可能性
- 注: FY2026の営業利益（42億円）は既に最終年度目標（37億円）を上回っている

## 6. サービス・その他

- **高速バス**: シートは4列／4列ワイド／3列独立／プライベートカーテン付き3列独立の4種（[バスとりっぷ](https://www.bushikaku.net/article/93493/)）。2023年10月に神戸〜岡山・倉敷線、姫路〜鳥取線（プリンセスバード）の神姫担当便を休止（[バスとりっぷ](https://www.bushikaku.net/article/178867/)）
- **キャッシュレス**: NicoPa（全国交通系IC対応）→ 2027年春に新ICサービスへ移行。観光周遊バス「シティーループ」「ポートループ」でクレジットカードのタッチ決済に対応済み（[Impress](https://travel.watch.impress.co.jp/docs/news/1570875.html)）
- **路線見直し**: 乗務員不足・コロナ禍により2021年4月から神戸市内で一部路線を休止・減便（[神戸市 地域公共交通会議](https://www.city.kobe.lg.jp/documents/24050/06_gijigaiyou.pdf)）
- **オープンデータ(GTFS)**: 今回の検索では神姫バス単独の公開ページを特定できず。GTFS-JPのオープンデータ一覧での確認が必要
