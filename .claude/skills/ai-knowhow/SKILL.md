# 社内AIノウハウ

Notion「AIインテリジェンス・ナレッジDB」(108件)から、検証を経たものだけを実行可能な形にしたもの。
検証の経緯と各項目の判定は `docs/AI_KNOWHOW_VALIDATION.md` にある。

## 全体を貫く原則(これだけは常に効く)

1. **プロンプトは Role + Context + Task + Format のラベル付き構造で渡す。** 思考手順は指示せず、タスクと制約を渡して任せる。
2. **「step by step で考えて」は書かない。** 最新の推論モデルは内部で段階思考するため、手書きCoTは逆効果になりうる。
3. **CONTEXT を厚くするほど品質が上がる。** モデルに推測させる余地を減らす。
4. **一発完成を狙わず「生成 → 批評 → 修正」のループを回す。** これが最短距離。
5. **1チャット = 1目的。** 無関係な話題を混ぜると文脈が汚れて性能が落ちる。

## 必要なときだけ読むファイル

| 何をするとき | 読むファイル |
|---|---|

| タスクに応じてモデルを選ぶ・コストを下げる | `references/model-selection.md` |
| 業務自動化・RAG/MCPを設計する | `references/design-checklists.md` |
| AI生成物を商用で使う・納品する | `references/design-checklists.md` |
| 画像・動画・スライド・音声・アバターを生成する | `references/media-generation.md` |

## 使う前に知っておくこと

`references/media-generation.md` の内容は**この環境では未検証**。画像・動画・音声の生成APIキーが無く、
各ツールの外部アカウントも未接続のため、記載は出典どおりの転記であり実行確認はしていない。
数値(価格・精度・スコア)を対外資料に載せる前に一次情報を確認すること。
