# 営業ノウハウ：自社 営業責任者の商談分析
出典: 営業研修資料.xlsx（インサイドセールス担当が営業責任者の商談tldvを視聴して抽出）
対象商談: 2025年5月〜7月／うち「営業責任者会心の一撃」2件は5回視聴の精読対象

---

## 0. 前提：自社が何を売っているか
- SNS（TikTok縦型ショート）を使った**採用マーケティング/ブランディング**の1年（または半年）伴走。
- 価格帯: 月50〜75万円。最低50万円を下げない理由・半年契約にしている理由をセットで説明する。
- 自社定義は「SNS会社ではなく**マーケティング会社**」。元はWeb広告/SEO、4年前にSNS事業へ。実績250社。

## 1. コアメッセージ（何度も繰り返される思想の柱）

### 1-1. SNSは目的ではなく手段
- 「SNSってあくまでSNS。会社の魅力とか目的を達成するための情報を発信する**手段の一つ**でしかない。**メガホンと同じ**」(5:54)
- 「SNSが一番レバレッジが効くし、世の中に一番広がるから手段として使っているだけ」(18:03)
- 「**目的と手段が逆転する**のがほとんど」(21:27)
- 「SNSを伸ばそうとすると変な方向に行ってしまう」(20:19)
- 「目的をフォロワーや再生数に置くのではなく、**御社と共鳴する理想人材**に置くことが大事」(13:43)

### 1-2. 採用は「選ばれる側」になった → 逆転手段はブランディング
- 「企業側が選ぶ時代は終わっていて、採用側が選ぶ時代になっている。逆転させる唯一の方法は**セルフブランディング**。**比較検討すらさせないのが究極の形**」(6:52)
- 「いい物を作る会社が残るのではなく、**ブランディングと認知ができた会社だけが残る**」(5:14)
- 「採用、集客は**ブランディングができた会社の産物**」(29:51)
- 「会社の内部を増強させたらブランディングが世の中に伝わり浸透する」(31:53)

### 1-3. 「フォロワー数は要らない」＝差別化の一丁目一番地
- 「必要な人に必要な部分を届けるから**フォロワーは必要ない**」(10:04)
- 「フォロワーや再生数が少なくても、ターゲットにしっかり届けられるかどうか」
- 「根本のブランディングとターゲットが明確じゃないから結果が出ないアカウントも多い」(12:34)
- 「マーケティングとブランディングができていないアカウントが**一番危険**」

### 1-4. 緊急性の作り方（「やった方がいい」→「やらないとまずい」）
- 「世間はSNSやったほうがいい物の感覚だが、我々は**やらないとまずい**物（緊急性が高い）」(35:28)
- 「**緊急性は低いけど重要性は高い**。だからSNSは後回しにされてしまっている」(36:40)
- 「一番ロスなのは**コストではなく時間**」(21:50)
- 「自信満々な営業ができるのも今のうち。同じ地域・同業がマーケ/ブランディングをやり出したら差別化は難しくなる。**本当に今しかない**」
- 「毎年どんな企業も**20%人が減る**と言われている」(18:55)

### 1-5. 資産性（価格の正当化ロジック）
- 「（50〜75万が）安くはないと思うんですけど、**何年で見ていくのか**にもよる。1年間75万円払い続けたとしても、**3年後も残り続ける**」(23:38)
- 「一つ一つの動画やTikTokアカウントが**2年後、3年後の採用に生きてくる**。いわゆる資産性が高い」
- 「**来年、再来年が楽になっていくような資産作り**が正しいSNS」
- 「こちらのタイミングで、いつでも好きな時に好きな人数を集められる**基盤**」（派遣スポット利用との比較）(22:20)

### 1-6. 定着率（他社が絶対に言えない一手）
- 「**定着率は出す内容によって変わる**」。ブランディング/マーケを優先→現場との認識ズレがない→だから辞めない
- 「定着率は従来の採用媒体より高いと言われている」(11:14)
- 「会社に何か共感したり惚れたりする所がないとすぐにやめる人が多い」(6:17)
- 「**お金で来る人はお金でやめる**。ネガティブなエネルギーを残してしまう」(49:13)
- 「大手に入ってもその人に合っているか分からないから**退職代行**を使って辞めていく負のスパイラル」(15:48)
- 「採用段階で**適正ではない人を間引いておく**必要がある。それが運用のコンセプト設計であり演者選定」

### 1-7. SNSの本質＝人間理解
- 「**SNSの本質は人間理解**」(12:49)
- 「SNSはITのように見えて、**人間理解のアナログ**」
- 「SNSの本質は、気が合う人たちと、出会ってないけど繋がれる」
- 「SNSは**この指とまれ**」
- 「SNSは熱量の高い人を集めるには最適」(4:47)

## 5. 商談の型（フロー）

```
1. アイスブレイク
   └ 先方のInstagram等の内容に触れる（事前リサーチのさりげないアピール）
2. 応募背景確認 / 目的確認
   └「訪問営業の人材獲得でお間違いないですか？」と具体で確認
3. 現状ヒアリング（HP・SNS・社員数・よく見るSNS）
4. 会社概要説明
   └ 代表紹介の際に「SNS屋さんではなくマーケティング企業」と定義し直す
5. 自己紹介（営業責任者個人の経歴・仕事観）
   └ ここが最大の差別化。人として好かれて契約に至るケースも
6. 事例紹介（砂建・神姫バス・トラストカンパニー等）
   └ 相手と同属性・同地域の事例を選ぶ。数字だけでなく「こうしたからこうなった」構造まで説明
7. 先方企業に当てはめる
8. 質疑 → 導入検討段階か情報集めかを聞く
9. スケジュール感の共有
10. プラン紹介と反応確認
   └ 最低50万を下げられない理由 / 半年契約にしている理由
11. SNS会社との違いを再度強調
12. 反応を見ながらビジネスプランの値下げを小出し
13. 次回日程調整（その場で決める）
```

### スケジュール感（必ず提示する具体数字）
- 5/1契約 → 初回撮影 5月4週目 → 初投稿 6月上旬 → **応募が来始めるのは8〜9月**
- 「8月から運用を検討している場合、世に知られるまで**1〜2ヶ月のリードタイム**が必要」→ 逆算して今動く必要性を作る

## 6. クロージング技術

- **言い切る**：悩みが出た一発目で「**結論、解決できると思います**」と言い切る → 着地点を先に明示して自信を見せる
- **前提で言い切る**：「僕たちが結果を出しますので、**事例動画に出演していただきたいです**」(29:10) — 成功前提の依頼
- **奥の手は後出し**：最初からキャンペーン適用を開示せず、金額で悩んだ様子を見てからワンプッシュ
- **懸念の言語化**：「検討する」と言われたら、**何が懸念点なのか**を必ず問う
- **予算を聞く**：金額懸念には「情報収集も兼ねて、ご予算はいくらでしたか」
- **プラン階段**：年間契約 → 半年契約 → 内製化への橋渡し提案
- **期限を切って再検討**：前向きだが費用対効果が懸念なら、強引に押さない。期限を設けて再検討させる。ただし他社との違いだけは明確に残す
- **その場で次回日程**を必ず決める
- **仮押さえ**：4ヶ月先の話でも仮押さえしておく
- **交通費込み**が意外と刺さる
- **初回撮影のタイミングから支払いを発生させる**：我々にも責任感が生まれる、という誠実さの提示

## 7. 切り返し（反論処理）

| 相手の言葉 | 対応 |
|---|---|
| 「広告や無料媒体でダメだった時に初めて検討する」 | ※未解決の課題として記録されている（要スクリプト化） |
| 「決裁権が社長にある／社員では説得が難しい」 | 直接出向いて説明するケースもある |
| 「SNSは内製化している」 | 「情報提供だけ／時間の無駄になるかもしれない」と前置き。**押し売りは絶対にしない**、必要のない相手には提案しない |
| 「動画の所有権は？」 | 即答（契約書に記載）。即時返答が信頼性になる。※すぐ出ない時は2秒の間や聞き返しも手 |
| 「知り合いが自力でTikTok採用をやってうまくいっていない」 | SNSへの漠然とした不安。戦略性がないから結果が出ない、と構造で返す |
| 「他県で同業がもう運用している」 | 実績を細かく紹介しつつ「**地域は関係ない**」と印象づける |
| 費用対効果への懸念 | 半年プラン＋人員構成の違い（人件費2人分）＋総務/人事へ内製化のバトンを渡せる |

## 8. ヒアリング・共感の技術

- 相手の意見に**寄り添って返す**（例：オンラインMTGで背景を入れるのが嫌いな社長 → 自分も背景を入れない）
  - 先方の言い分：「Zoomはオンラインだからできるだけ対面に近い形にしたいのに、背景やぼかしを入れられるとリアル感から遠ざかる」
- **曖昧な質問は聞き返す**：「ご縁をいただいた時のその後の流れ、ということですか？」→ 意図確認＋「ご縁をいただく」という語彙自体が信頼を作る
- **業界理解を示した上で投げかける**：「こうではないですか？」→「この人は真剣に向き合ってくれている」と思わせる
- **共感しながら自分の意見を交える**：否定的にならず、考えてくれている印象を作る
- **質問を先回りして答える**（ニーズを読み切る）
- **結（結論）から話す**：起承転結の「結」から入るとスッと入る
- **緩急**：熱く話す場面と、冷静にゆっくり落ち着いて話す場面を使い分ける

## 9. 企画・運用設計の知識（デリバリー側のノウハウ）

- **本音と建前**：「本音と建前ばっかり動画に出していくと離れていきやすい」(9:43)／「**悪いと思っているところも発信していく必要がある**」(9:55)
- **ギャップ設計**：「○○だけど、こんな良い一面もあります」を見せると求める人材が集まる
- 「一般的に見たら印象を悪くするような動画でも、本当に欲しい人材・想いを持っている人に届けば人が集まる」
- 「発信の内容に嘘をつかなければ、自分で見て自分で感じて選んで申し込みをしてくる」
- 「**なぜそこで働いているのか**という正体を突き詰めて動画で表現する」→ 共感する人＝長く働く人が集まる
- 「**会社を辞めていない理由**は強い」
- 「長所と短所はあるが、それは**個性**」→ 求める人材に合わせた見せ方を行う
- **社長についてきてほしくない**クライアントもいる → 思いを汲んだ構成にする
- MVV（ミッション・ビジョン・バリュー）でいいなと思う部分を分析し**言語化**する → 同じ属性の人が集まる環境を作る
- 「まともな人ならどんな人でもいい」と半分諦めている経営者 → **それだと逆に集まらない**。「こういう人がいい」と決めないと求職者側も選べない
- 「同じ会社でも色んな人が色んな考え方を持って選択している」→ 見るべきはSNSではなくマーケ＆ブランディング
- 「会社のメリット・デメリットは人によって変わる」（仕事の面白さ／給与／人間関係）
- **縦型ショート**なら TikTok / YouTube / Instagram に横展開できる
- 「いつどこで誰に見られても伝わるブランディング動画」＝SNSが日常の一コマだから
- **インナーブランディング**としての価値も訴求できる(49:40)
- クローズドな空間（公式LINE・採用HP）に誘導する(5:07)
- 「マッチングの精度がズレると求めている属性外の求職者が集まる。属性を理解すればイタチごっこではなくなる」
- 「会社側から**選り好みしたほうがいい**」(21:40)
- 「**誰が言うか／どう伝えるか／誰に伝えるか**」(19:55)
- 「人間性を見せることが遠回りに見えて一番レバレッジが効く」(12:00)
- 「この動画を見たときに相手がどう思うかをイメージし、そこから**逆算**しないと採用につながるSNSは作れない」(18:58)
- 地域性の活用：沖縄の綺麗な海は住民には日常、県外には非日常 → **焦点の当て方を変える**
- 競合不在の地域は「**一人勝ちできる**」と強くプッシュ（心理に訴える）

  - マーケ/ブランディングコンサルは"ないものを売る"ので実態がないと思われがち。特にオフライン畑・高齢の経営者

## 11. 教育・育成の設計として学べること
- 「**営業責任者会心の一撃**：この商談をマスターできれば即戦力なので最優先で**5回**見てください！※他の商談10個見るより価値ある」
  - 対象2件：見込客A＠（社名伏せ）（7/8）、見込客B社長＠（社名伏せ）
  - **同じ商談を5回見て、毎回違う観点でメモを取る**という学習法が実際に運用されている
- 振り返りフォーマット（3列）：
  1. 率直な感想
  2. この商談から得た気づき・学び
  3. **自分の商談に取り入れようと思った具体的なフレーズ2つ（話された時間も表記）**
- 未経験者の心理も資産として記録している：「営業責任者のすごさに心が折れかけたが、同時にベンチマークになった。未経験の今の状態でこう思ったという事実はとても大事で、残しておくことに意味がある」
