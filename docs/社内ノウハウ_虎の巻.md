## 1. 営業の型（商談で繰り返し効いているもの）

### 1.1 コアメッセージ

- **SNSは目的ではなく手段。** 「SNSはメガホンと同じ。会社の魅力を届けるための手段の一つでしかない」
- **採用は「選ばれる側」になった。** 「逆転させる唯一の方法はセルフブランディング。**比較検討すらさせないのが究極の形**」
- **フォロワー数は要らない。** 「必要な人に必要な部分を届けるからフォロワーは必要ない」——競合との一丁目一番地の差別化。
- **緊急性の作り方。** 「世間はSNSを『やったほうがいい』物と捉えているが、我々は『やらないとまずい』物として扱う」「一番のロスはコストではなく時間」
- **資産性で価格を正当化する。** 「1年間払い続けても、3年後も残り続ける」「来年・再来年が楽になっていく資産作りが正しいSNS」
- **定着率は他社が言えない一手。** 「お金で来る人はお金で辞める」「採用段階で適正でない人を間引いておく必要がある。それが運用のコンセプト設計であり演者選定」

### 1.2 効いている比喩

| 比喩 | 使いどころ |
|---|---|
| メガホン | SNS＝手段であることの説明 |
| 卓球選手にテニスを頼む | SNS会社に採用を頼む違和感 |
| 魚がいないところで魚を待っている | 媒体・ターゲット設計のズレ |
| 合コン | 「自分の好みをはっきりさせないと向こうも動けない」＝ターゲット明確化 |
| 人件費2人分 | 月額を安く感じさせる換算 |
| 穴の空いたバケツ | ボトルネックを直さず応募だけ増やす愚 |
| ポケモンのレポート | 細かく合意形成を取ることの説明 |
| 「◯◯地域の△△屋さんと言えば御社」を作る | 相手の社名を入れて未来を想像させる。表情が変わる |
| 戦争の情報収集 | 3C分析の説明。「競合＝敵、市場＝戦場、自社＝自分の兵力（資金・サービス・人）」 |
| ギターの弾き方は分かっているが、相手が気持ちいい音を出せるか | 知識と「使える」の差の説明（育成場面） |

### 1.3 クロージング

- **言い切る** — 悩みが出た一発目で「結論、解決できると思います」。着地点を先に示す
- **成功前提で頼む** — 「僕たちが結果を出しますので、事例動画に出演していただきたいです」
- **奥の手は後出し** — キャンペーンは最初から開示せず、金額で悩んだ様子を見てから
- **「検討する」には懸念を必ず問う**
- **その場で次回日程を決める。** 4ヶ月先でも仮押さえする
- **初回撮影のタイミングから支払いを発生させる** — 「我々にも責任感が生まれる」という誠実さの提示になる
- **提案書の最後に「本日決めたいこと」を3〜5点置く** — これがあると商談がその場で進む（→ 9.2）

### 1.4 顧客に語ってもらう構造を作る

> 「顧客側が『良い』と広めてくれる先導者を作る方が、こちらから『商品が良い』と伝えるよりも効果的」

エリアで結果が出ている顧客には合同面談の形で他の顧客をつなぐ。**各エリアで代理店やお客様を作る感覚で進める。**

## 2. 相手の懐に入る（信頼を作る技術）

年間7億をクロージングした営業責任者が社内セミナーで解体して見せたもの。

### 2.1 「任せる」と言わせる4つの前提条件

1. 彼は**自分のルーツを把握している**と知っているから信用する
2. 彼は**自分の目的とゴールを理解している**と知っているから任せる
3. 彼の頭の中には**すでに構想が完成している**と知っているから信用する
4. 彼は**自分よりこのプロジェクトに夢中だ**と知っているから任せる

信頼が取れていないときは、この4つのどれかが欠けている。「何を話したか」ではなく「この4つが相手の中に立っているか」で点検する。

### 2.2 言葉 < 行動 < 状態

> 言っていることとやっていることが一貫している人はほとんどいない。**やり続けた結果、今どうなっているか**——その状態に目を向ける。

「ココ・シャネルは人を判断するときに**お金と時間の使い方**を見ると言った。お金と時間＝命なので、その使い方が本質にすごく近い」

### 2.3 肩書きを外す

「どんな社長も普通の人。悩むし、お腹も空く。**そこと向き合い始めるとめっちゃ早い**」

「『これから社長のことを普通のおっちゃんとして見させてもらいます』と言うと喜ばれる。**自分をそう見てくれる人が周りにいないから**。銀行は金づるとして見るし、社員は本音を言わない」

### 2.4 主語の移動 — 否定せずに方向を変える

I（私は）／You（あなたは）／We（我々は）／社会から見ると、を切り替える。

「『そう見せたいんですね。**でも社会から見るとそう映りませんか**』と言うと、『ないかもね』『新しい気づきをありがとう』となる」

> **否定したくなる状況は「目的とゴールの認識が一致していない」サイン。** 技術で押し切らず、認識合わせに戻る。

### 2.5 ヒアリングの最優先は「とにかく安心させる」

> **安心感がないお客さんほどハレーションが起こる。** 人は、不安に思ったとき、あるいは**自分が大事にされていないと思ったとき**にクレームを出す。

1. めっちゃ相手を見る
2. 相槌のトーンを注視する（同じ「なるほど」でも理解度が違う）
3. **細かく合意形成を取る** — 「ポケモンでいうといちいちレポートを書いている感じ」
4. **細かく自分の感想と感情を伝える**（最も見落とされている）
5. 目的とゴールをやりすぎなぐらいすり合わせる

> 現場での実感：「**打ち合わせの1時間を丸々ヒアリングに充てて、AIにナレッジを蓄積していく**」というやり方に価値がある（週報より）。

### 2.6 担当者は板挟みである

「担当者は**上司と取引先の板挟み**。怖い人2人に挟まれている」
「**契約を続けようが続けまいが、担当者の固定給は変わらない。** 選べるなら放り出したいじゃないですか」
「だから**続けることでその担当者の社内での立場が上がる**ようにしてあげる」

> **成果が出ているのに解約されるケースの多くは、担当者が味方になっていないから。** 報告先を決裁者だけに置くとこの構造を見落とす。

**担当者がボトルネックになっている場合の外し方**（デコボコベース様の実例）

1. まず**1回目はその担当者経由で正式に依頼する**（順序を飛ばさない）
2. 返ってこなければ、決裁者に「この方だとプロジェクトが止まってしまうので、別の方を立ててください／◯◯さんを動かしてください」とアスクする
3. **顔を潰さない言い方をする**。「◯◯さんが安心できるように、こちらで巻き取ります」という立て付けにする

### 2.7 ⚠️ これは諸刃の剣である（本人の警告）

> - 「信頼と期待の獲得が大きい分、**結果を出せなかったときにめちゃくちゃ燃える**」
> - 「炎上している案件がある。理由は**言ったことをやっていないから**」
> - 「逆に、入り込まなければ責任も求められない。**クライアントによってはそれでもいい**」

導入するなら「関係性がまだ深まっていない相手で、小さく試す」。

## 3. 継続防衛（切られる前に効く手）

### 3.1 「勝ちパターン」を言語化して合意する

採用に直結する数字が出ていない時期は、**中間指標の勝ち筋を定義して握る。** ただし必ず質で縛る。

> 質のいい認知の取り方です。ラーメンを食べてデタラメに伸ばしているわけではなく、**興味を持ってほしい人たちの定義を守った上で母数を増やせている**のが評価できるポイント。

### 3.2 再生数の「質」を読む

| | 動画A（再生数が多い） | 動画B（再生数は少ない） |
|---|---|---|
| 視聴維持 | 22秒でスキップが多い | **最後まで見る人が多い** |
| 解釈 | 「面白そう」で見た母数 | **本気で学ぼうとする＝求職者に近い層** |

**再生数が落ちた回こそ、視聴維持率で殴り返せる。**

### 3.3 数字は「ぶっちゃけベース」で出す

「直接流入は増えていない、とちゃんと言った方がいい。**ここが今少ないけど、こう増やしていきましょう**、が相手の欲しいもの」

> **事実を率直に出す → 相関効果を示す → 打ち手をセットで出す。** この順番を崩さない。

**相関で語る技術**（出光リテール販売様の実例）

- TikTokのプロフィール画面からの直接クリックは合計3件のみ → **直接効果は言いづらい**
- しかし**TikTok投稿日にGoogle/Yahoo検索経由のセッションが明確に伸びる**という相関がある
- → 直接流入の少なさを正直に認めたうえで、相関を説得力を持って提示し、**SEO強化というアップセルにつなげる**
  （検索順位10位前後 → 上位化でTikTokからの導線が強化され、セッションが増える、という筋）

### 3.4 満足度を点数で聞く

「10点満点で今何点ですか」と聞き、**足りない分の中身を必ず聞く。**

**実演例（アドプレイス様・月次）**

| 質問 | 回答 |
|---|---|
| 今月の我々の点数は？ | **9点** |
| 9点をつけた理由は？ | 再生回数だけでなく、コメントや興味を持った人にちゃんとリーチしている実感がある |
| 12点・15点をつけるとしたら何が足りない？ | **応募者数** |
| 何人来たら12〜15点？ | 月10〜15人 |
| 10件来たら何名が就労まで行く？ | 半分くらい |

→ **「月5名の就労で15点」という共通ゴールがその場で言語化された。**
逆に「そちらは何点ですか」と聞き返されることもある——そのときに答えられる準備をしておく。

### 3.5 投資回収を先に握る

継続の判断軸が「フォロワー」なのか「投資回収」なのかは、**クライアントによって違う。先に聞く。**

**デコボコベース様の実例**

- 本部の意向：**自社採用2件、または直営の利用者1件の獲得をもって投資回収完了**と見なす
- 採用単価は60〜130万円／年間支払額は約170万円 → **2件採れば回収**
- 回収が終わったら「残り予算をフォロワー・再生数に振ってよい」と明言された

> 「本部としてお金を出す以上、投資回収はしなければいけない。それが終わったなら、加盟店や業界にもっといい影響があるコンテンツでいいですよ」

**→ 回収ラインを数字で握れば、その先の運用は自由度が上がる。** 継続交渉の設計はここから逆算する。

### 3.6 「フォロワーを増やすフェーズ」と「CVフェーズ」を説明する

クライアントからよく出る質問：「またフォロワーを増やしに走るフェーズはいつですか？」

**回答の型**

- フォロワーは常に増やし続ける。ただし**フォロワー増を主目的にしたコンテンツ戦略は取らない**
- 今は「集めている人の質がいいか」を検証している段階
- 「6万を達成するためにコンテンツ軸を寄せることはしない。増えていく過程で6万に行くことはあっても」
- ただし**「◯万人は行っておきたい」という感情的な要望は成果と別に存在する**ことを認識する（切りの良い数字への欲求）

### 3.7 ボトルネックはSNSの外にあることが多い

応募が増えない原因が「認知不足」とは限らない。ファネル全体を並べ、**一番漏れている段**を特定してから打ち手を出す。

| 案件 | ボトルネック | 位置 |
|---|---|---|
| ラングローブ様 | 内定承諾率 **35%**（3人に2人が辞退） | 選考の最終段 |
| 東京ビックハウス様 | 応募 **22件 → 採用0**（選考の質・入社後ギャップ） | 選考の質 |
| ラウンジ永遠グループ様 | プロフィール → LINE転換 **0.025%** | 受け皿 |
| 桜交通様 | **応募完了の計測0件** | 計測そのもの |

**いずれも「再生数を増やす」では解決しない。**

### 3.8 未消化本数（ビハインド）の扱い

- **ビハインドを広告費で消化してはいけない。** 広告費を別途もらっている案件では特に厳禁（二重取りに見える）
- 広告で消化してよいのは、**先方が追加の広告費を出せないが広告を試したい**という限定的なケースのみ
- 基本の解き方は①撮影回数を増やして消化する ②**「後半に良い企画を置いているので、あえて今は撮っていません」という立て付けにする**
  （例：「4月入社のニューフェイスに密着した方が絶対いい。それに置いているので、無理にこの期間で消化しない方がよくないですか」）
- **ビハインド本数は正確に出す。** 曖昧なまま交渉に入らない

## 4. 営業台帳959商談からわかったこと

### 4.1 受注率を決めているのは「即決」

角度別の成約率を全量集計すると、**初回商談でその場で意思決定に入った案件とそうでない案件で、成約率が桁違いに割れる。**
持ち帰りになった時点で確率は大きく落ちる。だから商談の設計は**「持ち帰らせない」**ことに寄せる。

### 4.2 失注理由の内訳（全量調査）

最大の塊は**予算**。ただし中身を読むと、単なる「高い」ではない。

> 「採用予算は月10万円前後」「求人媒体に月10万円かけている月もある」「エージェント中心で、採用にあまり力を入れていないフェーズ」

**中小企業の採用予算の中央値は月10〜20万円帯。** 提示価格はその数倍になる。だから：

1. 予算帯が合わない相手には**そもそも提案しない**か、別商品を出す
2. 通すなら「求人媒体◯社分」ではなく**採用単価**で比較させる

### 4.3 契約総額の構造

実額は伏せ、標準単価を `P` とする。

| パターン | 単価 | 期間 | 契約総額 |
|---|---|---|---|
| 標準（最頻） | P | 6ヶ月 | 6P |
| 期間延長 | P | 12ヶ月 | 12P |
| 上位プラン | 1.5P | 12ヶ月 | 18P |
| 下限帯 | 0.6P | 12ヶ月 | 7.2P |

> **12ヶ月契約は6ヶ月の2倍の売上だが、単価は同じ P。値引きせずに期間を延ばすのが最も効率のいいアップセル。**
> 獲得コストは契約時に一度だけ発生するので、12ヶ月契約は回収期間を半分にする。
> 営業に持たせる目標は「単価」ではなく**契約総額（単価×期間）**。

### 4.4 契約期間の使い分け

新規案件では**「6ヶ月契約」と「12ヶ月契約」を心理的ハードルで使い分ける**。
1年で検討していたものを特別に6ヶ月にした場合は、**6ヶ月分の穴埋めをRPOや保証で用意する**という交渉パターンがある。

### 5.2 Wantedly（最も体系化されている）

**アルゴリズム3系統**

| 表示形式 | 決まり方 | 運用側の打ち手 |
|---|---|---|
| おすすめ | 滞在時間ベースのAI判定 | ブラックボックス。狙わない |
| 人気 | 実態は「応援数」順でほぼ決まる | 一定コントロール可能 |
| 新着 | 新規公開順。既存記事の編集では再表示されない | **複製して出し直す**のが露出機会になる |

> 注目度ランキングはPV連動で上がるが、候補者からランキングを見る動線はほぼ無い。社内アピール指標としての意味合いが強い。
> 応援数を稼ぐ施策は、エントリー率が目安水準に達した記事ができてから。**応援だけ多くて応募につながらない記事の量産が失敗パターン。**

**KPI定義と目安**

| 指標 | 定義 | 目安 |
|---|---|---|
| エントリー率 | 1エントリー獲得に要したPV数の割合 | **1〜2%**（50〜100PVに1応募） |
| ブックマーク比率 | エントリー数に対するブックマーク数 | **エントリー数 > ブックマーク数**を目指す |
| 募集記事PV数 | 実現可能なPV獲得ができているか | 東京・大阪×3〜5職種で運用3〜4ヶ月後に月800〜1,000PV |

**読み解き**：エントリー率が低い＝タイトル・写真は良いが記事内容以降で離脱。ブックマークがエントリーを上回る＝興味はあるが応募への一押しが足りない。

**募集記事の型**

- **タイトル** ＝「フック（ひきのある情報・インパクトのある数字）× ベース（基本情報・社会貢献・入社の決め手）」
  - 例：「ベルギー1部リーグスポンサーを務める会社 × トップセールスを目指しませんか？」
  - 「上場企業・上場グループ」「AI」ワードは効果的（Wantedly担当者評価済み）
- **エリア設定** ＝主要都市を広く選択（東京のみ→東京+大阪等で**PV約2倍・応募約2.5倍**の実績）
- **稼働条件** ＝箇条書きで明確に。文章に埋め込んだ曖昧な書き方は見落とされ有効応募率を下げる。フルフレックスなら**月間稼働時間（例：160時間）**を明記
- **カテゴリー選定** ＝スカウト検索画面で必須スキルワード＋職種フィルタをかけ、**対象人数の多いカテゴリーから優先出稿**
  - 実例（編集者）：「デザイン・アート」が対象人数最多で最優先 →「その他」→「マーケティング」(356件) →「編集・ライティング」(200件)。従来出していた「PM・Webディレクション」は非効率だった

> ⚠️ **誤解しやすい点**：エリア選択欄は「**面談を行う場所**」の指定であり「勤務地」ではない。勤務地は「こんなことやります」欄に明記する。

**出稿ペース**

| 状況 | 推奨ペース |
|---|---|
| 通常運用（半年〜のPDCA） | 月1回程度でも可。基本軸は3ヶ月固定、タイトル・写真等の細部のみ都度調整 |
| 1ヶ月以内の短期決戦 | **3日に1回**ペースで新規公開（複製して出し直す）。週1本が最低ライン |
| 職種ごとの記事数目安 | 月15〜20記事公開し、職種別に訴求の勝ちパターンを探す |
| 求人合計本数（代行利用時） | 月合計50本前後（検証軸4パターン程度のときの最適値） |

**スカウト運用**

- 短期決戦では**無料スカウトを積極的に打つのが必須施策**
- 対象の探し方：必須スキル（例：Adobe Premiere Pro）を1つ入れて職種カテゴリでフィルタ。完全一致しなくても類似・上位互換スキル保持者がヒットする
- 候補者インサイト：スカウト画面「絞り込み」→「自社への興味」から、ブックマーク／閲覧／フォローした候補者のプロフィールを分析し、次の訴求仮説に反映

**ストーリー記事**

目的は、募集記事（2000字制限）で伝えきれない魅力を訴求し態度変容を促すこと。
概念整理：**採用広報＝未認知層への認知獲得／採用狭報＝既に興味のある層へのナーチャリング**。

| 大分類 | 小分類（全27カテゴリー） |
|---|---|
| 社員インタビュー（4種） | 代表／役員・事業責任者／マネージャー×2／メンバー×2 |
| ビジョン・事業計画（6種） | MVV紹介／事業部紹介×2／サービス紹介・事業展望／受賞者インタビュー／役員陣対談 |
| 仕事内容・職種紹介（2種） | 業務内容紹介×2（職種ごとの解像度向上） |
| キャリアパス・研修（3種） | オンボーディング紹介／キャリアパス紹介×2 |
| カルチャー・風土（1種） | 社内イベント紹介 |
| 環境・制度（6種） | 働き方／1on1面談／成長環境／面接官紹介／評価制度／待遇・福利厚生 |
| その他（2種） | まとめ記事／Q&A記事 |

- **まず出すべき「型」は8〜9本**（代表インタビュー・事業紹介・業務内容紹介・入社理由対談等）。各社ほぼ共通構成
- **本数は「数より質」。** 年間10〜15本程度
- **動線設計が必須**（直接流入は少ない）：募集記事に差し込み／初回メッセージ／スカウト文章／採用サイトバナー／他求人媒体へ挿入／まとめ記事化してエージェント配布
- **デザイン**：TOP・ストーリー・募集記事でトンマナ一貫。写真は明るい場所・シンプルな背景（観葉植物程度がベスト）、ロゴ切れ注意、服装2パターン以上。刷新でPV・応募とも約1.3〜1.4倍の実績

> ⚠️ **混同注意**：「月50本前後」は**募集記事**の新規出稿数であり、**ストーリー記事**の本数ではない。

**採用ブランディング設計フレームワーク（汎用）**

- **採用ブランディング8項目**
  - Company：Philosophy（創業の想い・Mission・Vision）／Product（誰のどんな課題を解決するか・競合優位性）／Market（市場成長性・業界内ポジション）
  - Career：Profession & Phase（やりがい・スキルアップ・組織フェーズ）／Career（得られるスキルの将来性・転職市場価値）
  - Culture：Person（経営陣・メンバーの人柄）／Culture（価値観・社風）／Privilege（働き方・福利厚生）
  - Technology：技術スタック・選定理由・開発カルチャー（エンジニア向け）
- **3C分析（採用版）**：市場・求職者 × 採用競合 × 自社 → Fit分析／Avoid・Watch分析／Differentiation分析 → **勝てる土俵（Winning Zone）／避けるべき土俵（Losing Zone）**と採用コンセプトを導出
- **採用シナリオ設計**：ペルソナごとに「インサイト／訴求軸／キーメッセージ／面接でのアピールポイント／CX設計／期待KPI」を一覧化
- **タレントプール構築**：今すぐ採りたい候補者と半年後・1年後の候補者を区別し、連絡タイミングを個別設計する
- **STAR面接**（構造化面接）：過去の状況・思考・行動を深掘りする質問設計。カルチャーフィット重視の人柄採用と相性が良い

**トレプロの採用戦略仮説**

- 強み仮説＝**「カルチャー・キャリアパスの独自性」**。「感謝・感動・感激」を土台に、本人のやりたいことに合わせて新しい事業が増えていくキャリアパス。「入社1年で役員登用」等の実例を、実際にそのキャリアを歩んだ社員の言葉で伝えるのが差別化の鍵
- 動画クリエイター採用の独自論点＝**フリーランス層の正社員化**。「会社の中でやった方が面白い」と思ってもらう状態をどう作るか
- 人柄採用の基準（社内共通言語）：**グロースマインドセット**（努力で成長できるという思考／対義語＝クローズドマインドセット）／「感謝・感動・感激」／仕事ができても人として働きにくい人はチームに不要

| 表示回数・クリックが少ない | 露出不足 | 有料（スポンサー求人）で露出強化 |

### 5.5 ビズリーチ

スカウト型ダイレクトリクルーティング。**成果はスカウト文面と対象選定でほぼ決まる。**
料金は初期費用0円、基本利用料85万円〜（例：85万円で6ヶ月＋プラチナスカウト400通）＋成功報酬（理論年収の15%〜が目安）。

> ⚠️ **コスト感**：プラチナスカウトは1通あたり約2,000円相当。**通数を「消化」する運用ではなく1通ずつ丁寧に使う。**

**返信率を上げる文面設計（4要素）**

1. 候補者のプロフィール・レジュメへの具体的な言及（なぜあなたに送ったのか）
2. その人のどの経験が自社で活かせるかを個別に整理して提示
3. 入社後にどんなキャリアが描けるか
4. 自社の魅力とミッションを簡潔に

| 運用 | 返信率 |
|---|---|
| 現職社名の差し込み程度のテンプレ | **0.7%** |
| レジュメを読み込んだカスタマイズ送信 | **2.6%** |

- 文面のトーンは、過度にへりくだらず**自信と熱意が伝わる言い切り型**
- **スカウト担当を明確にする。** 担当が曖昧だと「忙しくなると放置→リマインド→また放置」で属人化する
- 固定費が発生するため、**採用要件と送信リソース（誰が何通送るか）を決めてから契約する**

### 5.7 クラウドワークス／ランサーズ（業務委託）

**共通の型**

- 動画編集の報酬相場例：短尺（TikTok・広告動画）1本1万円前後〜、企業紹介ムービー10〜30万円

> ⚠️ **偽装請負リスク**：指揮命令・専属拘束が強くなると労働者性の問題が出る。**契約形態と実態を一致させる。**

|---|---|---|
| 発注者手数料 | 原則なし（契約金額のみ） | 依頼無料。特定の支払い方法で事務手数料が発生する場合あり |
| ワーカー側手数料 | 約16.5% | 16.5%（一律） |
| 継続契約 | プロジェクト継続 | **月額報酬プラン（手数料5%／税込5.5%）** |
| 人材の見極め | 実績・評価・ポートフォリオ | 上記＋**認定ランサー制度** |

## 6. SNS運用の型（媒体特性と設計）

### 6.1 媒体ごとの役割分担

| 媒体 | 役割 | 出すもの |
|---|---|---|
| TikTok | **発見・入口**（若年・潜在層への拡散） | 短い知識、ビフォーアフター、意外なポイント、賛否の分かれるネタ |
| Instagram リール／プロフィール | **検討・信頼**（世界観・人物ブランド） | 社員の顔、実態、FAQ、保存されるまとめ。家族への共有・安心形成にも寄与 |
| YouTube | **納得・登録**（長尺で深く伝える） | ドキュメンタリー、代表の解説、仕入れ〜販売の裏側 |
| X | **告知・拡散** | 求人情報・イベントの即時告知、他媒体への導線 |
| LINE | **受け皿**（応募・問い合わせ導線） | 15分面談予約、エントリー、登録アンケートで流入元可視化 |

**尺の役割は明確に分かれる**（東京ビックハウス様の実データ）

| 尺 | 本数 | 視聴中央値 | 登録合計 |
|---|---|---|---|
| ショート（<60秒） | 27 | 1,189 | +7 |
| ミドル（60-89秒） | 29 | 750 | +29 |
| ロング（90秒〜） | 41 | 610 | **+253** |

→ **登録の85%超がロング。ショートは認知、ロングは登録。** 役割を混同しない。

### 6.2 YouTube と Instagram はユーザー心理が真逆

| | YouTube | Instagram |
|---|---|---|
| 流れ | ノウハウ→知識→問題解決→「この人誰だろう」→登録 | ライフスタイル→価値観→人柄→憧れ→信頼→商品・サービス |
| 順番 | **情報 → 人** | **人 → 情報** |
| 評価される単位 | 動画（情報） | プロフィール全体（人物・世界観） |

- YouTubeでは視聴者の**半数以上、場合によっては7〜9割が未登録ユーザー**
- Instagramリールは発見タブ経由でTikTok的に消費されるが、**フォローされる理由は人**
- 従ってInstagramは**アカウントを分散させない**（人格を一箇所に集約／商業感を減らす／フォローの心理的ハードルを下げる）
- 投稿の役割分担：ライフスタイル＝世界観・憧れ／仕事風景＝信頼／リール＝新規接点／ストーリーズ＝距離感／カルーセル＝価値観を深く
- プロフィールは「何をした人か」より**「何を信じている人か」**

### 6.3 採用アカウントを「メディア」に転換する型

```
役立つ情報で集客 → 会社への信頼 → 仕事への興味 → 顧客の問い合わせ／採用応募
```

- **求職者向けに寄せすぎるより、会社全体の魅力が分かる発信の方が結果的に採用にもつながる**
- 業界不信がある領域では、**他社批判をせず「自社の仕事・基準・工程を見せる」ことで誠実さを証明する**
- **属人化を防ぐ体制**：代表一人に依存せず現場社員も出演。「代表が現場を訪れ、仕事やこだわりを質問する」形式が有効
- 初心者向けと専門家向けで企画を分ける。専門用語を使いすぎない。求人情報だけを連続して発信しない

### 6.4 クリエイティブ評価の4指標（再生数では判断しない）

| # | 観点 | 指標 | 意味 |
|---|---|---|---|
| 1 | 入口 | CTR（サムネ×タイトル） | クリックされたか |
| 2 | 中身 | 平均視聴率／完視聴（フル視聴） | 最後まで見られたか |
| 3 | ファン化 | 保存／登録者増 | 関係が構築できたか |
| 4 | 行動 | プロフィール遷移 | 採用意欲につながったか |

> ⚠️ **「再生数の罠」＝空バズ。** ターゲット外に届いた再生は成果ではない。
> 実例（東京ビックハウス様）：「新NISA」は**90,721再生だがフル視聴率0.66%・平均視聴3.3秒**。「安心して働ける環境」は17,718再生だが**女性比率34%**（通常は男性85%）＝相手がズレた。

### 6.5 採用スコア — 応募数が取れないときの代理指標

| 指標 | 定義 | 採用との関連 |
|---|---|---|
| プロフィール遷移率 | プロフ閲覧数 ÷ 再生数 × 100 | 「この会社を知りたい」＝採用意向の最初のアクション |
| フォロワー転換率 | フォロワー増加数 ÷ 再生数 × 100 | 「継続的に情報を得たい」＝採用ファネルへの流入 |
| **採用スコア** | プロフ遷移率×0.5 + フォロワー転換率×0.3 + 完視聴率×0.2 | 採用効果の総合スコア（0〜1） |
| バズスコア | 再生数×0.6 + おすすめ率×0.4 | 拡散効果の総合スコア（0〜1） |

**採用スコア × バズスコアの2軸で全動画を4象限に分類**すると、「バズったが採用に効かない動画」が可視化される。

### 6.6 見る数字（成果指標の全体構造）

```
再生数 → 完視聴率 → プロフ遷移率 → クリック率 → アクセス数 → CVR → 応募数
```

**KPI基準値（採用SNSの社内基準）**

| 指標 | 基準値 |
|---|---|
| 完視聴率 | 25〜40% |
| プロフ遷移率 | 0.3〜2% |
| クリック率 | 10〜30% |
| CVR | 3〜15% |

- 顧客向けと採用向けの問い合わせは**分けて計測する**
- 短期目標は「まず問い合わせ3〜5件」のように**小さく具体的に**置く
- 保存数とプロフ遷移率の相関は **r=0.761**（強い正の相関）。コメント r=0.693、シェア r=0.643。**「後で見返したい」＝真剣に検討しているサイン**
- 一方、**ER（エンゲージメント率）と採用指標の相関は r=−0.308**（弱い負の相関）。**ERを主KPIにしない**

### 6.7 目標値は「中央値」で置く

再生数の目標を過去のバズ実績で置くと、**毎月1本はバズらないと未達**という設計になってしまう。

> 「平均で出すより中央値で出す。バズらなくてもなんとかなりそうな数字で作る」

### 6.8 コメント欄は開けるのが原則

コメント欄を閉じているアカウントは伸びない。

> 「コメント欄を開放していたら2000フォロワーで止まっていない。絶対に質問が来ている」

- 閉じる理由の多くは**現場スタッフの尊厳を守るため**。その懸念自体は正当なので、頭ごなしに否定しない
- 開放を提案するときは、**丁寧にコメント返信をしている他社事例**をセットで見せる（例：スマイル・リンク様は全件返信）
- アンチコメントは一定数来る。**それを楽しめる出演者かどうか**で判断が変わる

## 7. 制作・編集の実務（品質とリスク）

### 7.1 ⚠️ 求人動画で金額に触れるとシャドウバンになる

複数アカウントの事例を突き合わせた結果、共通していたのは金銭表現だった。

- 「稼げます」のような直接表現だけでなく、**「月収◯万円スタート」のような具体的な金額提示でも落ちる**
- 疑わしい副因：**倍速のかけすぎ**（機械音声と判定される可能性）、モザイクの甘さ
- 一度落ちるとアカウント作り直しになり、**再生数もいいねも作り直し前の水準に戻らない**

> **社内では「シャドウバン」を重大インシデントとして扱っている。** CC部門が全社の過去事例を調査・整理し、ナレッジシェア会（2026-08-12）で「原因の考え方／復旧事例／予防の仕組みづくり」を全社共有した。
> 課題認識：**回復が難しい事例が続いており、CC単独の対策では限界がある。MM・クライアントを含めた見直しが必要。**

> ⚠️ **ただし**：東京ビックハウス様の分析では「43万」「車が買える」など**具体的な金額こそがCTR・視聴率を押し上げている**（CTR 10.7%＝全体最高）。
> 金額を「訴求として使う」ことと「求人動画で稼げる系の直接表現をする」ことは別物。**媒体・文脈・表現の仕方で線を引く。**

### 7.2 撮影の基準

- **ショート動画はHD（1080）で足りる。** 4Kが要るのはYouTube併用・HP掲載・ハイエンド案件のとき
- **「肌を綺麗に見せたい」への正しい回答**は解像度ではなく**色とビット数**。数値を変えたパターンを事前に出し、**一番納得したものを基準値として固定する**と毎回の揉め事がなくなる
- **撮影は「引き」で撮る。** 演者の周りに余白があるほど編集で調整できる
- **縦型・小型機材**（スマホ・小型マイク・ジンバル）で現場の負担を最小化
- **1回の撮影から複数本を切り出す。** 1回の同行で5〜10本分の素材を確保。撮影1時間で**ショート約12本 or ロング2〜3本**
- **字幕は標準装備。** 冒頭の「つかみ」と末尾の応募誘導を定型化し、無音再生に最適化
- **服装は同じものが望ましい。** 「映像で見た時に同じ服の方が覚えてもらいやすい」

> **なぜ基準を決めるのか**：「クライアントが気づかないうちにこちらの都合に合わせさせられている状態で、人によってばらつきがあるのは良くない。自分が払う側だったら嫌じゃないですか」

> **美容案件での学び**：「美容の人は肌をきめ細やかに見せたいわけじゃない。むしろ飛ばして、ぬめっとさせてほしい。一般の人が見たら少し不自然なくらいに」

### 7.3 素材が悪ければ編集では救えない

> 「元の素材が悪ければ、いくら編集を頑張っても無理。切り取るところがない」（玉乃光様案件）

**イメージがつかないまま撮った初回素材は、作り直しを提案する。** 編集で無理に成立させようとすると、時間もかかり品質も上がらない。

### 7.4 公開前 QAチェックリスト（自社セルフチェック）

クライアントに指示出し・修正作業という手間をかけさせないため、**公開前に100%セルフでクリアすべき基準。**

**① 一発アウト：表記・固有名詞**

- [ ] 業界固有語の誤変換（例：不動産の「棟数」を「頭数」／「源泉営業」を「厳選営業」）
- [ ] **呼称の全社統一**（例：「お客さん」→「お客様」。テロップ・音声とも）
- [ ] カタカナ標準化（マネージメント→マネジメント、プレーやー→プレーヤー）
- [ ] 動詞の漢字・ひらがな（契約を「挙げる」／名前を「あげる」／時間を「速く」／壁紙を「貼る」）
- [ ] **人名・部署名は社員リストと照合。** 固有名詞（商品名・人名）の間違いは致命的
- [ ] **金銭単位**（「1,000円」と「1,000万円」の取り違え）を前後文脈込みで確認

**② コンプライアンス・プライバシー**

- [ ] **人格否定表現は例外なく全カット。** 厳しさを残すなら人格ではなく「基準の低さ」「考え方の甘さ」を突くシーンを使う
- [ ] 背景の通行人（特に正面を向いた顔）、飛び込み先が特定できる建物・看板に**必ずモザイク**
- [ ] **【超重要】書類のボカシ。** 面接動画等で履歴書・レジュメがカメラ側を向いた瞬間、書類部分全体にモザイク
- [ ] 顧客アンケート・スピーチ内の個人情報／取引先情報、口コミの評価に関する生々しいくだりは全カット
- [ ] **AI BAN対策**：「自殺」「自死」等はテキスト・音声ともに原則カット
- [ ] **著作権・使用期限**：期限のある画像・BGMはスプレッドシートで期限を可視化し、期限前に差し替え

**③ テンポ・構成**

- [ ] 冗長な導入（前職の退職理由、長い経歴語り）は積極的にカット
- [ ] 社内システムを不必要に明かすシーン（適性検査の解説等）は削除
- [ ] テロップ・ロゴが TikTok／YouTube のシステムUIと被らないようセーフゾーン内に
- [ ] テロップは境界線・半透明ベース・コントラスト比で可読性を確保
- [ ] 音量の均一化（ノーマライズ／コンプレッサー）。質問者に合わせて演者の声が小さくならないように
- [ ] 環境音（サイレン等）は徹底除去。難しい場合は**撮影時に指摘する**

**④ 出演者の選定**

- [ ] **再現性のない組み合わせは原則ボツ。** 自律しきっていない新人と代表のサシ対話は対話が成立しない
- [ ] **背中で語れるキーマンを意図的に起用する**
- [ ] **代表依存を避ける。** 代表のスケジュールに撮影が縛られると本数が落ちる（東京ビックハウス様＝契約10本/月に対し実績7本）。月2回の撮影枠を曜日固定し、出演を約10名でローテーション
- [ ] **女性の出演者を確保する。** 女性利用者・求職者にとって同性がいることが安心材料になる。自社に女性がいない場合、グループ会社・別事業所から出てもらい「全員が映っている中に1人入っている」見せ方にする

**⑤ サムネイル運用**

- [ ] 動画に埋め込んだ形ではなく、必ず**画像（PNG/JPG）として別添で提出**。別画角の候補を3案提示
- [ ] ただ煽るだけ・属性を不快に切り取る表現は厳禁。**見る人を力づけ、行動を変えさせる格調の高い表現**にする
- [ ] **通常版と筆文字・シック版の2パターンを用意しABテスト**

**CTR上位のサムネ型4パターン（実データ）**

| 型 | 例 | CTR |
|---|---|---|
| 数字の提示 | 「0アポで43万?」 | 10.7% |
| チラ見せ | 「月初会議のチラ見せ」 | 9.7% |
| 直球募集 | 「日本一を目指す人を募集中」 | 8.9% |
| NG提示 | 「やってはいけないNG行動」 | 8.9% |

### 7.5 修正時のコミュニケーションルール

1. **修正箇所を明示する。** 「修正しました」ではなく「0:15のテロップを〇〇から××に修正」と具体的にテキストで報告する。**お客様に動画を最初から見直して差分を探させない。**
2. **納期を宣言して死守する。** 「本日〇時まで」と明確に宣言。遅れる可能性が判明した時点で即座に連絡する

### 7.6 業界別の表現規制

**美容・化粧品（薬機法）**

| NG | 書き換え |
|---|---|
| 治療 | 施術／改善／ケア／アプローチ |
| 治る・治す | 綺麗にする／整える／改善する |
| 生きた細胞 | 削除または別表現 |
| 根本的に改善 | 慎重に使用 |
| 絶対／たった1回で | 根拠のない断定は避ける |
| コラーゲン生成 | コラーゲンが生成されにくい方 |

**メーカー・PR案件（クライアント表現ルール型）**

Fire TV 案件で作った運用版チェックリストの構造がそのまま他案件に転用できる。

- **言い換え表（NG→OK）で機械的に潰す**（製品名の統一、最上級表現「究極／最強／史上最高」の禁止、裏付けのない比較の禁止、廃止・変更事項への言及禁止）
- **トーンの原則：前モデル・旧UIをネガティブに見せない。** 差分は「より○○」「一層○○」の**加算形**で書く
- **必須注釈は入れ忘れ＝差し戻し。** コンテンツ・サブスクに言及したら注釈を**動画内に3秒以上表示＋投稿文章内にも記載**
- **競合ロゴの映り込みゼロ**（Apple／Google／Samsung／Microsoft／OpenAI／Meta）。特に**スマホ撮影時のリンゴマーク**が事故頻発ポイント
- **開封＋製品カットだけはNG。実使用レポートが必須**
- **ステマ規制（景表法）**：`#PR`／`#プロモーション`を投稿冒頭に視認可能な形で表示。プラットフォームのタイアップ機能をON
- **社外配布前に消すもの**：開発コードネーム、本案件に不要な他カテゴリ規定、無関係なリンク

**業界特有のセンシティブ話題の扱い（福祉・医療等）**

不正受給・業界の闇など、**フックとしては強いが炎上リスクのある話題**の扱い方：

1. サムネイルには強めの言葉を入れてフックにする
2. ただし**最終的には「自社が健全に運営されているからこそ、危険な事業所の説明ができる」という逆の発想**に着地させる
3. **発言内容は事前に固め、クライアント社内チェックを通してから撮影する**

## 8. 企画・台本の型

### 8.1 採用アカウントの「まず作る7本」

大阪チタニウムテクノロジーズ様の企画設計が、採用アカウント立ち上げの標準形になっている。

| # | 本数 | 内容 | 狙い |
|---|---|---|---|
| 1 | 1本 | **求人募集動画A：会社としての安心感** | 「レアな事業」「安定している」「正社員として就職できる」。誇れる仕事に就きたい層に効く |
| 2 | 1本 | **求人募集動画B：具体的なメリット** | 報酬・休日・寮など、媒体に載せるような条件を前面に。**期間社員が対象なら時給とモデル月収を書く** |
| 3-4 | 2本 | **入社理由インタビュー（出演者ごと）** | 「なぜ入ったか」＋「入社後のライフスタイルのビフォーアフター」。募集動画で興味を持った人が必ず見る |
| 5 | 1本 | **仕事紹介** | 「実際どんなことをやるのか」。交代勤務・体力仕事も**隠さず伝える** |
| 6-7 | 2本 | **TikTok的リーチ獲得コンテンツ** | 給料日の「爆食」など、直感的な欲求に訴える映像で認知を取る |

> **設計思想**：1〜5は「採用に直結するが伸びにくい」コンテンツ、6〜7は「伸びるが直接は採用に効かない」コンテンツ。
> **後者が伸びることで前者が見てもらえる流れを作る。** この配分を毎月組む。

**求人募集動画は必ずプロフィールにピン留めする。** コメント欄に「気になる」が集まり、そのコメント自体が次の応募者を呼ぶ。

### 8.2 現場が撮れない場合の作り方

企業秘密・安全上の理由で作業風景が撮れない案件は珍しくない（大阪チタニウム様＝日本で2社程度しかないチタン製造）。

- 作業風景の代わりに**文字＋差し絵＋環境音**で伝える
- 背景は**白壁のオフィスを避け、工場の建物を背景にした屋外**にする（イメージが伝わる）
- 「当たり前だと思っている社内設備」が最大のアピール材料になる
  - 食堂（400円で十分・500円で満腹）／寮／**大浴場**／筋トレルーム／昼休みにサッカーができる場所／社内コンビニ
  - → **クライアント自身が価値に気づいていないことが多い。ヒアリングで掘り出す。**

### 8.3 厳しさは隠さない（ミスマッチを減らす）

> 「数を集めるのも重要だが、その上でミスマッチを減らしたい。これを見て応募してくれる人＝ある程度もう条件と働き方を覚悟してくる人になる」

ただし**厳しさだけを伝えると応募が止まる**ので、必ずセットで入れる：

- 研修制度
- 教える体制
- 「未経験でもみんなできるようになっている」という事実

### 8.4 シリーズ化で採用ファネルを設計する

シリーズ2本目以降は、**採用ファネルの深い層（検討段階）にリーチできる**。

```
①認知：「なぜ[会社名]で働くのか？」
②理解：「具体的な働き方・収入・環境」
③行動：「応募方法・入社後のサポート」
```

実データ（山謙様）：「16年続く理由①→②」で採用スコア65%維持／「山謙で続く理由①→②③」で109%向上。
**採用スコア0.4以上の動画は必ず続編を作る。**

### 8.5 月次企画の組み立て

- **常設コンテンツ（基幹）× 毎月の運用コンテンツ**の二本柱（→ 9.2）
- 前月に何を多く撮ったかで翌月の配分を変える
  例：2月に事業所紹介を多く撮った → 3月はリーチ拡大・認知に振る
- **視聴者の「知らない」に応えるチップス系**を入れる。ただし知識だけで終わらせず、**最後に必ず自社への相談導線に着地させる**
- コメント欄を分析して次の企画に反映する（「A型事業所とは何か」が分かっていない視聴者が多い、等）

### 8.6 台本の運用

- 台本は**撮影日の数日前までに送付**し、クライアント社内チェックの時間を確保する
- 議事録は**打ち合わせ後すぐに送る**（クライアントから明示的に求められることも多い）
- 初回のクライアントはほぼ全員不安を抱えている。**「1回撮影して出来上がった動画を見ればイメージがつく」と伝えて進める**

## 9. クライアント提出物の型（提案書・レポート・分析）

提出物そのものが最大のノウハウ資産。以下は実際の提出物から抽出した再利用可能な構成。

### 9.1 提出物の4分類

| 種別 | いつ出すか | 目的 | 代表例 |
|---|---|---|---|
| **① 提案書（新規・企画）** | 受注前・企画フェーズ | 現状分析→課題特定→打ち手→目標→体制→スケジュールで意思決定を促す | 桜交通様、ラウンジ永遠グループ様、さくらフォレスト様 |
| **② 月次レポート** | 毎月（提出期限＝第1金曜18:00） | 実績報告と来月方針の合意。継続防衛の主戦場 | 12社分を毎月一括制作 |
| **③ 分析レポート** | 契約更新前・方針転換時 | 蓄積データから勝ち筋・負け筋を抽出し、路線を決め直す | 東京ビックハウス様、山謙様、ノア歯科様 |
| **④ 調査報告書** | 立ち上げ・戦略設計時 | 一次情報から訴求軸を導出 | さくらフォレスト様デプス調査、桜交通様従業員アンケート |

### 9.2 提案書の標準構成（17セクション）

| # | セクション | 中身とポイント |
|---|---|---|
| 1 | エグゼクティブサマリー | 結論を1ページで。「認知は成功。次は受け皿とブランド」のように**現在地と次の一手を一文で** |
| 2 | 現状分析① 定量 | GA4アクセス分析、SNS実績。**良い点と伸びしろを並べる** |
| 3 | 現状分析② 定性 | 従業員アンケート、デプス調査。**一次情報** |
| 4 | 市場・競合 | 母数・単価・競合ポジション。**戦う場所を定義する** |
| 5 | ペルソナ設計 | タイプ別に属性・決め手・不安・訴求。**意思決定者が本人以外にいる場合は必ず書く**（例：家族の納得が決め手） |
| 6 | 課題とボトルネック | 応募ファネルの各段に大／中／小で詰まり度を付ける。**★最大のボトルネックを1つに絞る** |
| 7 | ボトルネック別の解決策 | 原因 → 解決策 → 期待効果の3列表。打ち手には**必ず順序をつける** |
| 8 | 目標設定（KGI/KPI） | 採用人数から逆算したファネル |
| 9 | 施策の方針 | 動画フォーマット、媒体役割分担 |
| 10 | 計測設計 | UTM／GA4イベント／ダッシュボード。**「計測を整えてから集客に投資する」を明記** |
| 11 | 企画カレンダー | 月別テーマ。常設コンテンツ × 毎月の運用コンテンツ の二本柱 |
| 12 | 制作の進め方 | 週次フロー。現場負担の小ささを明示 |
| 13 | 推進体制・役割分担 | **クライアント側の担当も明記する** |
| 14 | 想定されるリスクと対策 | 計測遅れ／出演者確保／後半失速／否定コメント。**先回りして書くこと自体が信頼になる** |
| 15 | スケジュール | 月別マイルストーン |
| 16 | 当面の進め方（直近2週間） | すぐ動く4項目 |
| 17 | **本日決めたいこと** | 3〜5点に絞る。**これがあると商談がその場で進む** |

### 9.3 月次レポートの型（スライド3ページ）

| ページ | 内容 |
|---|---|
| **P1 サマリー** | KGI／主要KPIの「目標 vs 実績」をバー等で可視化。達成率を明示 |
| **P2 分析** | Fact → 洞察（なぜそうなったか）＋今月のベスト投稿 |
| **P3 来月の打ち手** | アクションプラン＋満足度（5段階） |

**運用ルール**
- 数値の出所は**効果測定シート1つに統一**。プロジェクトシートへの数値再入力は廃止
- アナリティクス・LINE・応募数も効果測定シートにタブを追加して統合（別ファイルを増やさない）
- 効果測定シートをクライアントと共有し、**いつでも最新数値を確認できる状態**にする
- 責任分界：**作る＝TSP／伝える＝SSP／成果入力＝クライアント**（未入力時はTSPが代理記入）

### 9.4 月次レポート生成プロンプト（社内標準）

**STEP 1 ｜ KGI設計**

入力：クライアント名／アカウント名／プラットフォーム／ビジネスゴール／業種・業態／過去データの有無
出力：KGI（指標名＋目標値）とアカウントKGI（指標名＋目標値）

> ⚠️ 必ず「指標名」と「目標値（数値）」をセットで。**「認知度向上」「ブランディング強化」など数値化できない表現は不可。**

**STEP 2 ｜ KPI設計**

- **マーケティング指標（2つ）**：KGIに直結するビジネス成果を測る指標＋目標値＋選定理由
- **アカウント指標（3つ）**：マーケ指標を達成するために伸ばすべきプラットフォーム上の指標＋目標値＋選定理由
- すべて「○○件」「○○%」「○○秒」など毎月計測・比較できる数値指標にする
- **プラットフォーム外データ**（LINE登録数・予約数・来店数・売上・問い合わせ数・ECセッション等）が含まれる場合は、クライアントに ①現在値 ②月次で取得可能か ③取得元 を確認する

**STEP 3 ｜ 月次振り返り**

Fact / 傾向（3つ）・洞察（3つ）・来月以降の方針（3つ）を、それぞれ**1行で**出力。

**採用SNS版（応募数最大化フォーカス）**

```
構造：再生数 → 完視聴率 → プロフ遷移率 → クリック率 → アクセス数 → CVR → 応募数
KPI基準：完視聴率 25〜40% / プロフ遷移率 0.3〜2% / クリック率 10〜30% / CVR 3〜15%
```

**目標設定ルール**
- **最重要ボトルネックKPIを1つ特定し、そのKPIは +30〜80% 改善を許容**
- その他KPIは +10〜30% 改善で調整
- 基準値未達 → 「基準値に近づけること」を優先／基準値内 → 上限寄せ or 微改善／基準値超過 → +10〜20%に抑える
- **KPIは単体でなく構造として整合性を保つ**
- **データ不足は「判断保留」とし、目標値も保留とする**（曖昧なまま数字を置かない）

**評価ルール**：基準値未満＝悪い／基準値内＝普通／基準値上位・超過＝良い／データなし＝保留
**制約**：*Factと洞察を混ぜない。抽象表現禁止（数値または行動を含める）。保留は明確に記載する。*

### 9.5 分析レポートの型

**構成（東京ビックハウス様・総合版）**

1. **結論を先に**：勝ち筋は◯つ、負け筋は◯つ、そして「再生数の罠」
2. **クリエイティブ評価の新基準**を提示（→ 6.4 の4指標）
3. **通年比較で「1本の力」の変化を見る**（1本あたり視聴・総視聴・登録者増・CTR）
4. **勝ち筋を具体例で示す**（数字／物語／リアル／行動と欲の肯定／CTRの型）
5. **負け筋を明示する**（抽象格言の量産／ターゲット外の空バズ）
6. **視聴者属性がターゲットと合っているかを検証**
7. **クリエイティブの外の課題も出す**（受け皿・効果測定・制作オペレーション）
8. **統合結論＝次に作るべきものを1つに束ねる**
9. **これから測る指標とアクション・タイムライン**

> ⚠️ **1本依存に注意**：総視聴の2/3が1本の動画から来ているなら、それは実力ではない。通年比較のときは必ず中央値と分布を見る。

**6W3H 分析テーブル（山謙様）— 網羅的に見落としを潰すフレーム**

```
列構成：分析軸 / 分析項目 / 内容 / 根拠（データ） / 採用への影響 / 改善アクション
```

| 分析軸 | 何を問うか |
|---|---|
| What | 効いている動画／効いていない動画の特徴は何か |
| Why | なぜ効くのか（求職者心理との一致／信頼性／CTAの有無） |
| Who | 視聴者と採用ターゲットにズレはないか／ターゲットの困りごととの一致度 |
| When | 投稿曜日・時間帯との相関／シリーズ投稿の効果 |
| Where | コンテンツ種別ごとの効果比較／保存・シェア・コメントとの相関 |
| How | 改善施策（①CTA設置 ②テーマ最適化 ③ファネル設計 ④配分最適化 ⑤初動強化） |
| How much | 各施策のインパクトを★5段階＋試算で示す |
| How many | 再現可能な「勝ちパターン」をテンプレート化する |

**最後は必ず「改善施策 優先度まとめ」で締める**：優先度／施策／インパクト／実施コスト／即効性／採用への影響

### 9.6 調査報告書の型（デプスインタビュー）

目的は**「採用・広報・制作の三者が同じ判断を下すための共通言語」**を作ること。

1. エグゼクティブサマリー（**三行結論**＋最重要インサイト＋発信の核）
2. 調査概要（目的／手法／対象者／時期／質問設計／分析の流れ／対象者一覧）
3. 個票分析（対象者ごとの詳細）
4. **インサイト分析**：`表層ニーズ（本人の言葉） / 深層心理（本音の解釈） / 裏付けとなる声`
5. 共通点マップ（観点／頻度 n分のm／共通点／根拠は誰か）
6. 意思決定プロセス分析（認知→興味→検討→参加→揺らぎ→定着）
7. 障壁・不安マップ（障壁／誰が／放置した場合のリスク／SNSでの克服法）
8. **訴求軸**（軸ごとに：刺さる相手／背景インサイト／コアコピー／バリエーション／企画案／媒体別／NG）
9. コンテンツの柱 × 媒体マトリクス（◎主力／○展開／△補助）
10. **発言バンク**（テーマ別の生の発言集＝そのまま台本になる）
11. 考察と提言（ネクストアクション）
12. **調査の限界と今後**（サンプルの偏り・定性の性質・検証方法を正直に書く）

**この型から出た普遍的な学び**

> **① 恐怖 > 夢。** 人は「なりたい姿」より先に「なりたくない自分」を語る。発信は逃げたい現実から入る方が刺さる。

> **② 弱み・違和感は隠すと不信になり、先に出すと"ふるい"になる。** 正直な開示は、合う人の信頼を勝ち取り、合わない人を気持ちよく帰す両得の手段。

> **③ 「軽く入れて、深く惹き込む」の二段構造。** 入口は全員軽い。決め手は極めて深い人的接触。SNSは軽い入口の最大化装置。口説き切ろうとせず「まず話を聞きに来い」までを目的にする。

### 9.7 従業員アンケートで逆算する

提案・企画の精度を上げる最短ルートは、**今いる社員に聞くこと**。

**設計**（東京ビックハウス様の実施例）

- 対象：**営業職の全社員**（126名規模）
- 形式：Google フォーム・**完全匿名**・10〜15分で終わる分量
- 目的：入社決定プロセスの各フェーズ（知る → 興味を持つ → 他と比較する → 決める）で**何を考えていたかを逆算する**
- 使い道：フェーズごとに作るべきコンテンツが決まる。競合と比較しているときの心情に対して、どのコンテンツを当てれば自社に来てくれるかが分かる

> ⚠️ **上辺のアンケートになると意味がない。** 「経営陣には見せない、誰が書いたか分からないようにする」と明言し、本音を書いてもらう。

**桜交通様での実例**（約150名回収）

- 勤続10年以上が48%＝**定着の良さ**
- 未経験入社は約3割で増加中
- **入社前の最大の不安は「大型バスを運転できるか」→ ほぼ100%が研修・先輩の指導で解消**
- → **研修密着シリーズが最重要コンテンツ**という結論が、データから直接導かれた

### 9.8 採用された人にインタビューして再現性を作る

1件でも採用が出たら、**その人にリクルートジャーニーマップを作る。**

- 所要：Zoom で 1〜2時間
- 内容：会社を知ってから採用に至るまでの心理を全部洗い出す
- 使い道：**そのジャーニーから逆算したコンテンツ設計**を組む
- 効果：「こういう人は再現性を持って採れる／採れない」の判断までつく

> **質問項目を専門担当に作ってもらえば、誰が聞いても同じ情報が集まる仕組みになる。**

## 10. 運用事例カタログ

### 10.1 ラングローブ様（中古車販売／SNS採用）— ボトルネックはSNSの外にあった

**運用実績（5〜7月）**

| 指標 | 変化 |
|---|---|
| 再生数 | +26%（4,564 → 5,763） |
| 視聴維持率 | **+39%**（6.7% → 11.1%） |
| フル視聴率 | 1.9% → 3.0% |
| プロフィール閲覧 | **+86%**（35 → 65） |
| 検索経由の視聴 | 5〜26%で発生。**指名検索が発生** |

**勝ち筋の言語化** ＝「車・実車系」または「社長・社員のリアル系」 × 短尺60秒前後

**発見したボトルネック**

- サイト訪問は年初来10,660人＝**集客はできている**。一方フォーム応募は年間10件、6月以降は1件のみ → LINEへ切替
- 最大のボトルネックは**内定承諾率35%**。辞退先は大手自動車小売の高固定給、他業界（SaaS等）
- 試算：**承諾率を65%に上げるだけで、応募数そのままで年間約12名＝目標到達**

**提案の構成**

| 提案 | 費用 | 内容 |
|---|---|---|
| ① オファー面談の導入 | **0円** | 内定当日に電話→48時間以内に面談。「なぜあなたを選んだか」＋条件・昇給の道筋を直接説明。代表メッセージ動画＋期限までLINEフォロー。進行台本・想定問答・フォロー文面は自社で用意 |
| ② エリア別・応募直結広告 | 月10万円／2週間テスト | 冒頭をエリア別に差し替えた6パターンを各店舗の商圏だけに配信。評価指標を「再生単価」から**「応募1件あたりのコスト」**へ |
| ③ Instagram同時展開 | 無償（特別対応） | 週5本リール横展開。プロフィールをLINE直行に。**内定検討中に見られる受け皿**として承諾率も下支え |

> **4月の広告との違い**：従来は「再生数」目的で53万再生・応募0。今回は「応募直結」設計。**目的指標を変えることが本質。**

**方針側**：「求人情報の掲示板」→「会社全体の魅力が分かるメディア」へ転換／業界不信には**他社批判ではなく自社の工程を見せる**／「役立つ車の知識」が伸びる（ホイール動画は広告なしで約12,000回再生）／出演は**代表が現場に質問する形式**で属人化を防ぐ。

### 10.2 東京ビックハウス様（不動産・源泉営業）— 「厳しさのブランド化」と勝ち筋の実証

**採用ブランディング・キャンバス（6要素）**

| 領域 | 内容 |

2. 役職者を**「採用数」ではなく「育てて残した数」で評価**
3. 根本原因を潰す（当たり／差別的扱い／入店ギャップ／稼げない／孤立）
4. **30日／90日オンボーディング・1on1で辞める前に拾う**
5. 出戻り歓迎・グループ内異動を良い循環に
6. **定着率・離職理由を数字で管理**

**長期戦略：追う採用 → 集まる採用**（宝塚モデル：選抜育成／憧れの頂点と階段／物語×ファンダム／セカンドキャリア）

### 10.8 デコボコベース様（障害福祉FC本部）— 投資回収の握り方

**構造の理解**

| 回収経路 | 単価 | 回収の速さ |

→ **本部の意向は明確：「自社採用2件、または直営の利用者1件で投資回収完了。その後はフォロワーに振ってよい」**

**コンテンツ軸の転換とその説明**

- 当初：フォロワー・再生数を増やす面白い動画 → 1月から「採用・集客に確実につながる」軸へ変更
- 結果：リーチは減ったが**1月に採用が決まった**

**LP計測が遅れた原因と対処**

- LPの権限をもらうのに時間がかかり、流入・ユーザー動向が追えていなかった
- → **原因はクライアント側の担当者。** 決裁者に「この方だとプロジェクトが止まる」と伝えて体制を変える（→ 2.6）

## 11. 社内オペレーション（会議体・提出物・データ）

### 11.1 会議体のリズム

散在していたカレンダー登録から復元した、**週次・月次の固定リズム**。新しく入った人が最初に把握すべきもの。

| 会議体 | 曜日・時刻 | 目的 | 出るべき人 |
|---|---|---|---|
| **【内M】MM企画アップデート** | 毎週金 8:00 | 各アカウントの企画進行を横並びで確認。詰まっている企画をその場で解く | MM（メディアマネージャー）全員 |
| **プロデューサー会議** | 毎週金 9:00 | 継続角度・体制・数字。経営に近い意思決定 | プロデューサー／責任者 |
| **CEO Vision & ASK** | 毎週日 10:30 | 会社の方向性の共有と、現場からの ASK（要望）の吸い上げ | 全社 |
| **Weekly Report** | 毎週金 17:00 | 週次の実績報告。数字と課題を出す場 | 全員 |
| **プロジェクトシート** | 第1金曜 18:00 | 月次の全案件棚卸し。継続角度と打ち手を全件レビュー | 全員 |
| **経費精算** | 前月21日〜当月20日締め | 締め日を跨いだ経費は翌月扱い | 全員 |

**この設計の意図**：
- **金曜に集中**している。企画（8時）→ 経営（9時）→ 実績（17時）と、同じ日に「作る話」「決める話」「振り返る話」を並べることで、週を金曜で締め切る構造になっている
- **日曜の CEO Vision & ASK** が週の起点。方向性を先に受け取ってから月曜が始まる
- **月次はプロジェクトシート1本**に集約。案件レビューを分散させず、第1金曜に全部やる

### 11.2 カレンダー登録ルール（SMチーム確定版）

カレンダーは「自分の予定表」ではなく**チームの可視化装置**として運用する。だから記法を統一する。

| 接頭辞 | 用途 | 例 |
|---|---|---|
| **【内M】** | 社内ミーティング | 【内M】MM企画アップデート |
| **【お打ち合わせ】** | クライアントとの打ち合わせ | 【お打ち合わせ】〇〇様 定例 |
| **【作業】** | 自分の作業ブロック（他者からの割り込み防止） | 【作業】△△様 台本執筆 |
| **【架電】** | 電話・アポ取り | 【架電】新規リスト |

**登録前チェック3点**：
1. **接頭辞は付いているか** — 付いていない予定は、他の人から見て「何の時間か分からない時間」になる
2. **クライアント名は入っているか** — 誰の案件かが一目で分かること。「打ち合わせ」だけの予定は情報量ゼロ
3. **関係者は招待されているか** — 特に制作側。招待漏れは「聞いてない」を生む最大の原因

**運用上のポイント**：**【作業】を積極的に入れる**。作業時間をカレンダーに置かないと、その時間は「空いている時間」として他人に消費される。制作・編集の集中時間は自分で守るしかない。

### 11.3 プロジェクトシート運用（月次）

**目的**：全案件の状態を同一フォーマットで並べ、継続角度の低い案件を早期に発見して打ち手を打つ。

**TSP / SSP の責任分界**（→ 用語辞書も参照）：

| 区分 | 略称 | 担当領域 | プロジェクトシートでの記入責任 |
|---|---|---|---|
| **作る側** | TSP | 撮影・編集・投稿・クリエイティブ品質 | 制作進行、本数消化、品質課題 |
| **伝える側** | SSP | クライアント折衝・企画・数値報告・継続 | 継続角度、クライアント温度感、次月方針 |

**分けている理由**：この2つを1人が兼ねると、**制作が遅れているときにクライアントへの報告が甘くなる**（自分の遅れを自分で報告することになるため）。分けることで、報告の客観性が保たれる。

**スライドは3ページ固定**（月次運用の稟議フォーマット）：
1. **実績** — 本数、再生数、応募数、KPI 達成率
2. **課題と原因** — 数字が動かなかった箇所と、その根本原因
3. **次月アクション** — 誰が・いつまでに・何をするか

**根本原因を3層で掘る**（プロジェクトシートの分析欄）：

| 層 | 問い | 例（応募が来ない案件） |
|---|---|---|
| **表層** | 何が起きたか | 応募が0件 |
| **中層** | なぜそうなったか | 動画は回っているが、プロフィールから求人ページへの導線がない |
| **深層** | なぜそれを放置したか | 「再生数」を KPI にしていて、導線を誰も見ていなかった |

深層まで降りないと、翌月も同じことが起きる。**「再生数を増やす」は打ち手ではない**（→ 3.7 ボトルネック）。

**新3点方式**（レビューを速くするための簡略運用）：
- **① 継続角度（%）** — 数字1つ
- **② ボトルネック（1行）** — どこで詰まっているか
- **③ 今月の打ち手（1行）** — 誰が何をするか

全案件をこの3点で並べると、**低い順にソートするだけでレビュー順序が決まる**。詳細はシートの下段に置き、会議では3点だけ見る。

### 11.4 提出物チェックリストと請求

- **提出物チェックリスト**：案件ごとに「提出すべきもの／提出済み／未提出」を管理する。月次レポート、分析レポート、企画書、請求書などが対象。**未提出の放置がクレームの温床**になるため、月次で棚卸しする
- **請求テンプレート**：フォーマットを固定し、案件名・期間・金額・内訳の記載を統一。イレギュラー請求（追加撮影、スポット制作）は必ず事前に見積を出してから
- **原則**：**「言った・言わない」を残さない**。金額と納品範囲は必ずドキュメント化してクライアントと共有する

## 12. PM体制と意思決定

出典：**トレプロ社側体制図（最新版）**。誰が何を決めるか、迷ったら誰に聞くかを明文化したもの。

### 12.1 体制の3レイヤー

| レイヤー | 役割 | 担当領域 |
|---|---|---|
| **戦略・統括** | 案件全体の方向性と、クライアントとの合意形成 | KGI/KPI 設計、提案、継続判断 |
| **制作** | 企画・撮影・編集・投稿の実行 | クリエイティブ品質、本数、スケジュール |
| **分析サポート** | 数値の収集・可視化・示唆出し | レポート、効果測定、競合分析 |

**3層に分ける理由**：戦略と制作を同じ人が持つと、**「作れる範囲の提案」しかしなくなる**。分析を別に置くと、戦略・制作のどちらの都合にも寄らない数字が出る。

### 12.2 意思決定フロー

| 領域 | 起案 | 承認 |
|---|---|---|
| **戦略（方向性・提案内容）** | 三並 | 橋口 |
| **PM（進行・体制・アサイン）** | 三並 | 永井 |
| **制作（企画・クリエイティブ）** | 福岡 | 三並 |
| **分析（レポート・数値設計）** | 川島 | — |
| **RPO（採用代行領域）** | 山中 | — |

**運用ルール**：
- **起案者は「案」ではなく「決めたいこと＋推奨案」を持ってくる**。選択肢を並べるだけの相談は差し戻し
- **承認者が不在のとき**、起案者は「期限までに反対がなければ実行する」形で進めてよい。止まることのコストのほうが大きい
- **領域を跨ぐ判断**（例：制作の都合で戦略を変える）は、必ず上位レイヤーの承認を取る

### 12.3 権限範囲

| 判断内容 | 誰が決めてよいか |
|---|---|
| 企画の細部・演出・台本の言い回し | 制作担当が単独で決める |
| 撮影日程の調整、投稿タイミング | 制作担当がクライアントと直接調整可 |
| 月次の KPI 目標値の変更 | 戦略レイヤーの承認が必要 |
| 契約金額・契約期間の変更 | 承認者（橋口／永井）まで上げる |
| 新規の追加提案 | 戦略レイヤーで起案し承認 |

**原則**：**現場で決められることは現場で決める**。上に上げるのは「金額」「期間」「約束の変更」の3つ。それ以外を上げると意思決定が詰まる。

### 12.4 日次・週次・月次の動き

**日次**：
- **コメントチェック** — 投稿した動画のコメント欄を毎日見る。炎上の芽と、企画のヒントの両方がここにある
- **進捗確認** — 担当案件の制作進行を1日1回確認
- **感謝の表明** — チームメンバーやクライアントに対して、その日の助けに対して言葉で返す。**明文化されているのが特徴的**

**週次**：

| 曜日 | やること |
|---|---|
| **月** | 分析。前週の数値をまとめ、動いた／動かなかった要因を特定 |
| **火〜木** | 企画会議・レビュー・競合分析。作る時間 |
| **金** | 最終チェック・週次報告。締める時間 |

**月次**：
- **KPT**（Keep / Problem / Try）— チーム単位の振り返り
- **世界観の棚卸し** — 各アカウントが目指している「見え方」がブレていないかを確認する。運用が長くなるとコンテンツが場当たり的になるため、月1回引き戻す

### 12.5 依頼の基本形

> **（感謝）＋（依頼内容）＋（理由）＋（期限）＋（感謝）**

```
いつも助かっています。
〇〇の件、△△をお願いできますか。
××という理由で、この部分が先に決まると後工程が動けます。
□日の△時までにいただけると助かります。
お忙しいところありがとうございます。
```

**なぜ型にするか**：
- **理由**がないと、依頼された側は優先順位を判断できない
- **期限**がないと、必ず後回しになる
- **感謝で挟む**のは形式ではなく、依頼が積み重なる関係で摩耗しないための実務。特にリモート・非同期で効く

### 12.6 問題発生時の5ステップ

| # | ステップ | 具体 |
|---|---|---|
| 1 | **即時報告** | 隠さない・寝かせない。**分かった時点で報告する**。原因が分からなくても報告してよい |
| 2 | **事実確認** | 何が起きたかを、推測を混ぜずに確定させる |
| 3 | **原因分析** | なぜ起きたかを3層で掘る（→ 11.3） |
| 4 | **対策立案・実行** | 今回の火消しと、恒久対策を分けて出す |
| 5 | **再発防止** | 仕組み・チェックリスト・ルールに落とす。個人の注意力に依存させない |

**最重要は①**。→ 13.3 の「ミスは評価を下げないが、隠蔽は下げる」と対になっている。

### 12.7 3つのマインドセット

| # | マインドセット | 意味 |
|---|---|---|
| 1 | **成果への執着** | 「やった」ではなく「効いた」で判断する。本数を納めても応募が来ていなければ成果ではない |
| 2 | **チームへの敬意** | 自分の工程の後ろに人がいることを前提に動く。遅れは自分の問題ではなく、次工程の問題になる |
| 3 | **視聴者への想像力** | クライアントでも自分でもなく、**画面の向こうの求職者**が何を思うかから逆算する |

## 13. 組織運営と育成

### 13.1 継続角度（%）の運用

**定義**：各案件について「このまま行けば継続するか」を担当者が **%** で申告する数値。

| レンジ | 扱い |
|---|---|
| **80% 以上** | ノータッチ。上位者は口を出さない |
| **50〜79%** | 打ち手を確認。ボトルネックを一緒に見る |
| **50% 未満** | 介入。上位者が同席、または担当変更を検討 |

**80%以上ノータッチの意味**：**マイクロマネジメントをしないことをルールで担保している**。うまくいっている案件に上が介入すると、担当者の当事者意識が落ちる。介入の閾値を先に決めておくことで、「見られている感」ではなく「任されている感」で運用できる（→ 2.1「任せる」4条件と対応）。

**報告4点セット**（継続角度を出すときに必ず添える）：
1. **現在の数値** — 実績（再生・応募・採用）
2. **クライアントの温度感** — 直近の発言、要望、不満
3. **ボトルネック** — どこで詰まっているか（1つに絞る）
4. **次の打ち手** — 誰が・いつまでに・何をするか

この4点が揃っていない報告は、報告として受け取らない。「大丈夫です」だけでは判断できない。

### 13.2 クレーム対応と課題解決は分ける

**原則**：クレームが来たとき、**「謝る作業」と「直す作業」を混ぜない**。

| 作業 | 目的 | やること |
|---|---|---|
| **クレーム対応** | 感情の収束 | まず受け止める。言い訳・説明・原因の話を先にしない |
| **課題解決** | 事象の解決 | 事実確認 → 原因 → 対策。ここで初めて説明する |

**混ぜると起きること**：謝罪の場で原因説明を始めると「言い訳をしている」と受け取られ、感情が収束しない。逆に、感情が収束していない状態で対策を出しても聞いてもらえない。**順序が全て**。

### 13.3 ミスと虚偽の評価軸

> **ミスは評価を下げない。隠蔽・虚偽は評価を下げる。**

- 実行した結果の失敗は、**情報**として扱う。次に活きる
- **報告しなかったこと・事実と違うことを言ったこと**は、信頼の問題として扱う。これは別軸
- この線引きを明示しておくことで、**①即時報告**（→ 12.6）が実際に機能する。報告するとマイナスになる組織では、誰も報告しない

### 13.4 原価開示

- 案件の**原価をメンバーに開示する**。売上・原価・利益の構造を見せる
- **狙い**：「安く作れ」ではなく、「この金額の中で何を優先するか」を担当者が自分で判断できるようにするため。原価が見えないと、追加作業の可否を全部上に聞くことになる
- ※本ドキュメント内では単価を **P** でマスクしている（→ 4.3）

### 13.5 一人立ちの4フェーズ

**目安：入社7〜8ヶ月目で一人立ち**。段階を定義しておくことで、本人も上長も「今どこにいるか」を共有できる。

| フェーズ | 状態 | 判断基準 |
|---|---|---|
| **1. 同席** | 見て覚える | 打ち合わせに同席し、議事録が書ける |
| **2. 部分担当** | 一部を任される | 企画・台本など、特定工程を単独でこなせる |
| **3. 主担当（後見あり）** | 案件を持つが上長が後ろにいる | クライアント折衝を自分で回せる。判断は相談ベース |
| **4. 一人立ち** | 案件を単独で持つ | **継続角度を自分で読み、打ち手を自分で決められる** |

**フェーズ4の定義が「数字が作れる」ではなく「継続角度を読んで打ち手を決められる」**である点が重要。実績は運に左右されるが、判断力は再現する。

### 13.6 オンボーディングの内製

- 新メンバー向けの**オンボーディングアプリを自社で内製**している
- 背景：媒体マニュアル、提出物フォーマット、社内ルールが Drive に散在していて、新人が「どこを見ればいいか分からない」状態だった
- **本ドキュメント（虎の巻）自体がその延長**にある

### 13.7 プロデューサー会議で決まった運用方針

プロデューサー会議（毎週金 9:00）で確定した、組織側の重要決定。

| 決定事項 | 内容と背景 |
|---|---|
| **満足度連動インセンティブの全社導入** | クライアント満足度（10点法 → 3.4）を評価・報酬に連動させる。再生数や本数ではなく**満足度を指標に置く**ことで、数字合わせの運用を防ぐ |
| **情報隠蔽の禁止（明文化）** | → 13.3。ルールとして会議体で確認された |
| **CS担当を SSP にしない** | カスタマーサクセス担当が「伝える側（SSP）」を兼ねると、**クライアントの不満を吸い上げる役と、成果を報告する役が同一人物**になり、不満が上がってこなくなる。役割を分ける |
| **1人あたり約13アカウント** | 運用担当1人が持てるアカウント数の実測値。これを超えるとコメントチェック・企画品質が落ちる。アサイン計画の基準値として使う |
| **広告費15万より人材送客10名＠15,000円** | 同じ15万円を使うなら、広告出稿より**人材送客のほうが採用成果に直結する**という判断。予算配分の考え方として、クライアント提案にもそのまま使える |

# 第VI部　ナレッジ基盤

## 14. AI実務ナレッジ

出典：**Notion「AIインテリジェンス・ナレッジDB」（97エントリ）**。うち実務テンプレ／ベストプラクティスに分類されるものを中心に要約。

### 14.1 構造化プロンプトの基本型

社内標準テンプレート。**この4ブロックを必ず埋める**。

```
# 役割（ROLE）
あなたは〇〇の専門家です。

# 背景（CONTEXT）
（案件・目的・前提・制約・読み手）

# タスク（TASK）
（やってほしいことを具体的に。1つのプロンプトに1タスク）

# 出力形式（FORMAT）
（見出し構成／文字数／表形式／箇条書き など）
```

**ポイント**：
- **背景（CONTEXT）が最も効く**。役割だけ与えても、前提が無ければ一般論しか返ってこない
- **「step by step で考えて」は現行モデルでは逆効果**。推論モデルは内部で既に段階的に処理しており、指示すると出力が冗長になるだけ。**指示すべきは思考手順ではなく、前提と出力形式**
- 出力形式を指定しないと、毎回フォーマットが揺れて再利用できない

### 14.2 議事録 → 要約・タスク化

**用途**：Meet の文字起こし・Gemini メモから、そのまま共有できる議事録とタスクを起こす。

```
# 役割
あなたは議事録作成の専門家です。

# 背景
以下はクライアント〇〇様との定例打ち合わせの文字起こしです。
参加者：（社内）／（クライアント側）
この議事録は社内共有および次回打ち合わせの前提資料として使います。

# タスク
1. 決定事項を箇条書きで抽出
2. 保留・持ち帰り事項を抽出（誰が持ち帰ったかを明記）
3. ネクストアクションを「担当・内容・期限」の表で抽出
4. クライアントの発言のうち、温度感・不満・要望が読み取れる箇所を原文引用で抜き出す

# 出力形式
## 決定事項
## 保留事項
## ネクストアクション（表：担当／内容／期限）
## クライアントの声（原文引用）
```

**タスク4が実務上いちばん価値がある**。決定事項は誰でも拾えるが、**温度感は原文で残さないと消える**（→ 3.3 ぶっちゃけベース、13.1 報告4点セット）。

### 14.3 商用利用・著作権の安全運用チェックリスト

クライアント納品物に生成 AI の出力を使う場合の確認事項。

| # | 確認項目 |
|---|---|
| 1 | 使用したツールの利用規約で**商用利用が許諾されているか** |
| 2 | 生成物の**権利帰属**（ツール側 / 利用者側）を確認したか |
| 3 | **学習データ由来の類似**が疑われる出力になっていないか（既存の楽曲・キャラクター・ロゴに酷似していないか） |
| 4 | **人物の顔・声**を生成・変換していないか（肖像権・パブリシティ権） |
| 5 | クライアントの**社内規定**で生成 AI の使用が制限されていないか |
| 6 | 納品時に**生成 AI 使用の有無を開示**する必要がないか |
| 7 | 入力したプロンプトに**クライアントの機密情報**を含めていないか |

**7が最も事故りやすい**。未公開の採用計画、給与情報、社内資料をそのまま貼らない。**社外秘は要約・匿名化してから入力する**。

### 14.4 実務テンプレ・ベストプラクティスの索引

Notion「AIインテリジェンス・ナレッジDB」内で **実務テンプレ／ベストプラクティス** に分類されているエントリ（22件）の領域別マップ。

| 領域 | 内容 |
|---|---|
| **プロンプト設計** | 構造化プロンプトの基本型／指示の粒度／出力形式の指定／NG指示集 |
| **議事録・要約** | 文字起こし要約／タスク抽出／クライアントの声の抽出 |
| **企画・台本** | 企画案の発散／台本ドラフト／タイトル案の量産 |
| **分析・レポート** | 数値からの示唆出し／月次レポート生成プロンプト（→ 9.4）／競合分析 |
| **リサーチ** | 業界調査／競合アカウント調査／求職者インサイト |
| **権利・コンプライアンス** | 商用利用チェックリスト（→ 14.3）／表現規制の確認 |
| **基盤概念** | コンテキストエンジニアリング／Agent Skills／MCP |

### 14.5 基盤概念（用語の理解）

| 用語 | 実務上の意味 |
|---|---|
| **コンテキストエンジニアリング** | プロンプトの言い回しを工夫することではなく、**モデルに渡す情報そのものを設計する**こと。案件の前提資料、過去の議事録、フォーマット例を渡すほうが、指示文を凝るより効く |
| **Agent Skills** | 特定業務の手順書を AI に読ませて、毎回同じ品質で作業させる仕組み。**媒体マニュアルや提出物フォーマットはこの形に落とせる** |
| **MCP** | AI を外部ツール（Drive / カレンダー / Notion / Slack）に接続する規格。**本ドキュメント自体が、この仕組みで社内データを横断して作られている** |

### 14.6 運用上の原則

1. **AI の出力をそのまま納品しない**。必ず人が事実確認と temperature 調整をする。特に**数値と固有名詞**は誤りやすい
2. **プロンプトは資産として残す**。うまくいったプロンプトは Notion に登録する。個人の Chat 履歴に埋もれさせない
3. **機密情報を入力しない**（→ 14.3-7）
4. **AI が得意なのは「型のある作業の量産」**。企画の発想やクライアントの温度感の読み取りは人がやる
