# 撮影台本｜松島海岸駅前店（明日）

- **店舗**：松島海岸駅前店（観光立地）
- **紹介内容**：テイクアウト用 大判せんべい 3種／団子 6種／店内メニュー数品
- **出演**：焼長／加賀谷／ほやアイドル 萌江さん
- **狙い**：観光客の来店＋テイクアウト訴求。萌江さんのファン層へ拡散。1回のロケで複数本を撮り溜め。

## 出演者の役割（全編共通）
- **焼長**：職人・技担当。セリフ少なめ、一言が効く。焼き・割る・仕上げの“手元”が主役。
- **加賀谷**：MC・進行・ツッコミ。質問して萌江さんを立て、テンポを作る。
- **萌江さん**：ゲスト・観光客目線・リアクション担当。素直な感想と拡散力。

## 撮影順（香盤の目安／効率重視）
1. テイクアウト（せんべい→団子）＝日中の映え・観光感を先に
2. ASMR/シズル（割る音・焼き）＝静かな環境で
3. 店内メニュー（コラボ実食）＝仕込み・提供に合わせて
4. 集客・締め（店舗＆アクセス）＝最後にまとめ撮り
※ 各本、冒頭3秒の“強いカット”を必ず別撮りしておく。

## 本① 【観光フック】松島来たらコレ｜テイクアウト総まくり（30〜45秒）
- **フック(0-3秒)**：萌江さんが大判せんべいを両手で持ち「松島来たら、まずコレです!」＋パリッと割る音。
- **構成**：
  - 萌江さんが駅前店の前で観光客目線で登場
  - 大判せんべい3種を順に（名前テロップ）／焼長が焼きたてを手渡し
  - 団子6種をずらっと並べて“映え”カット
  - 萌江さん実食→素直なリアクション
- **セリフ例**：
  - 萌江「これ、食べ歩きにちょうどいい!」
  - 加賀谷「松島来たら、まずどれ食べる?」
  - 焼長（一言）「焼きたてが、いちばん。」
- **オチ**：「全部テイクアウトできます。松島散歩のお供に。」
- **CTA**：「松島海岸駅前店で。場所はプロフから」
- **テロップ**：「松島来たらコレ」→商品名→「テイクアウトOK」

## 本② 【ASMR・シズル】大判せんべいを割る音／焼きたて（20〜30秒）
- **フック(0-3秒)**：暗めの寄り、大判せんべいを両手で「パリッ!!」（特大の割れ音）。
- **構成**：焼き網の上でせんべいがふくらむ→焼きたてを割る音を3種分→湯気・香ばしさ。
- **ナレーション（最小）**：冒頭だけ「音、出してますか?」以降は音を主役に。
- **オチ**：割った断面のアップ＋萌江さん「いい音…!」
- **CTA**：「焼きたては、店頭で。」
- **テロップ**：「大判せんべい」→「この割れ音」

## 本③ 【食べ比べ・二択】団子6種、萌江さんの1位はどれ?（40秒）
- **フック(0-3秒)**：団子6種を一列にドン。「6種類、全部食べて1位決めます!」
- **構成**：
  - 6種を名前テロップで紹介（1本ずつ寄り）
  - 萌江さんが順に実食、加賀谷がコメントを引き出す
  - 1位発表は最後まで引っ張る（フォアシャドウ「1位、意外でした」）
- **セリフ例**：
  - 加賀谷「正直、どれが1位?」
  - 萌江「えー、迷う…でも私は——」（1位は最後に）
- **オチ**：萌江さんの1位＋「あなたの推しは?」
- **CTA**：「コメントで“推し団子”教えて」
- **テロップ**：常時「団子ランキング」＋各名称。1位は伏せて最後に。
- **横展開**：焼長の1位・加賀谷の1位で別バージョンも撮れる（シリーズ化）。

## 本④ 【コラボ実食】ほやアイドル萌江さん×焼長の牛たん（35〜45秒）
- **フック(0-3秒)**：焼長が炭火で牛たんを焼く「ジュッ」＋萌江さん「これ目当てで来ました!」
- **構成**：
  - 焼長の焼き（手元・火柱・返し）を寄りで
  - 焼きたてを萌江さんが実食→ガチのリアクション
  - 加賀谷が「ホヤの時ぶりですね」等、過去コラボに触れて親近感
- **セリフ例**：
  - 焼長（一言）「熱いよ。」
  - 萌江「んー!!(悶える)」
- **オチ**：萌江さん「これは並んででも食べてほしい。」
- **CTA**：「萌江さんも通う、松島海岸駅前店へ」
- **テロップ**：「ほやアイドル萌江さん来店」→「焼長のガチ牛たん」

## 本⑤ 【店内メニュー】至福の一口／限界チャレンジ（30〜40秒）
- **選択A（至福の一口）**：店内の名物を萌江さんが実食。アフレコ「至福の一口」トーンで。
- **選択B（ご飯何口いける?）**：萌江さんが挑戦、加賀谷がカウント煽り。口数テロップ常時表示。
- **フック(0-3秒)**：大盛り＋主役ドン「この一切れで、ご飯何口いける?」（Bの場合）
- **オチ**：記録発表＋「あなたは何口?」
- **CTA**：「コメントで挑戦表明」
- ※ 店内メニューの具体名は当日のおすすめに合わせて差し込み。

## 本⑥ 【集客・締め】松島海岸駅前店のご案内（20秒）
- **フック(0-3秒)**：駅・海岸のランドマーク＋暖簾。「松島の、この店です。」
- **構成**：外観→テイクアウト窓口→店内→3人で「お待ちしてます!」
- **必須テロップ**：店舗名・アクセス・テイクアウト対応・（あれば）営業時間。
- **CTA**：「松島観光の途中に、ぜひ。場所はプロフから」

## 当日の段取りメモ
- **冒頭3秒素材を各本ぶん別撮り**（割る音・ジュッ・団子ドン・萌江リアクション）。
- **音を録る**：割れ音・焼き音・咀嚼音・すする音。ガンマイク/ピンマイク用意。
- **観光感を出す**：駅名標・海・松島の景色を1カットは入れる（観光客の“自分ごと化”）。
- **萌江さんの見せ方**：素のリアクション最優先、アドリブ・笑いはカットしない。
- **焼長**：多くを喋らせず、技と一言で“かっこいい職人”に。
- **要事前確認**：せんべい3種・団子6種の**正式名称**、テイクアウト価格、店舗の営業時間・アクセス表記。

## 撮影後の投稿プラン（撮り溜めの回し方）
- 1回のロケで**6本＋横展開**＝約2〜3週間分の投稿に。
- 順番の目安：①観光フック → ④コラボ実食 → ③団子ランキング → ②ASMR → ⑤店内 → ⑥集客。
- 全本のKPIは「保存・コメント」。二択(③)とチャレンジ(⑤B)でコメント、テイクアウト(①②)で保存を狙う。
