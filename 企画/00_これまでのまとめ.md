# 利久SNS 検討まとめ（分析 → 戦略 → 実行）

このプロジェクトで出した結論と成果物の総まとめ。上から読めば「なぜこの戦略か」が一本で分かる。

---

## 1. 分析でわかったこと（現状）
### 効果測定（これまでの動画149本）
- **バズ力はある**（`ご飯が止まらない`245万 ほか）が、**失速中**。2025年に投稿がほぼ停止→勢い喪失、2026年は**フル視聴率2.6%まで崩壊**（＝冒頭で掴めていない）、フォロワー獲得も停止。
- おすすめ流入は70〜90%と高い＝**配信は来ているのに維持できていない**＝問題はフック（冒頭3秒）と維持。
- **再生数と“資産化”は別物**：チャレンジ企画は再生は出るがフォロワー・保存が育たない。職人・ASMR・コラボは再生中程度でもファン化に効く。

### 集客逆算（来店に近い指標＝プロフ閲覧・指名検索・保存）
- **「バズ」と「店を探す動き」はほぼ別物**（リーチTOP25とプロフ閲覧率TOP25の重複2本）。
- **最後まで見られる娯楽動画ほど店を探さない**（フル視聴率×プロフ閲覧率＝−0.37）。
- **店を探させるのは、炭火シズル・限定・こだわり系**（食欲＝行きたい）。テールスープ・こだわり牛たんが“リーチも集客も両立”の本命。

## 2. 戦略（結論）
### 土台：ブランディングの科学（バイロン・シャープ）
成長＝浸透率（想起される人数）。**メンタル可用性（思い出される）×フィジカル可用性（見つかる）**。差別化より独自性。休止＝忘却。KPIは行動。

### カテゴリーの真実 → 核ポジション
- **牛タン＝「ちょっとした贅沢」**。だから安売り日常戦（すき家・大戸屋）で戦わない。
- **牛タン専門で全国最大は利久**（約88店・全国 vs ねぎし約42〜53店・関東）＝「牛タン＝利久」は規模で取れるプロトタイプ。
- **核**：
  > 「“ちょっと贅沢したい”に、炭火の牛タン。牛タンなら、利久。」

### 想起の問題と解決
利久を思い出す瞬間が少ない（マック/すき家のような日常トリガーが無い）→**「頑張った日＝ご褒美」など頻度の高い場面に牛タンを接続**して想起を増やす。

## 3. 想起の設計（CEP＋独自資産＋可用性）
- **CEP（思い出す場面）**：頑張った日のご褒美／給料日／金曜／出張・旅先／がっつり満足／一人外食／家族／寒い日／手土産・家ご褒美／記念日。
- **独自資産（毎本固定＝識別性）**：暖簾・炭火の火柱・焼長・麦飯おかわり・テールスープ・統一テロップ様式。**音を消しても利久と分かる**状態に。
- **フィジカル可用性**：全国88店舗「お近くの利久で」。プロフに店舗検索・予約・テイクアウト・お取り寄せ導線。指名検索対策。松島など限定はローカルCTA。

## 4. コンテンツ（2大シリーズ＋3レイヤー）
### 旗艦シリーズ（アカウントの背骨）
- **A「ご褒美メシ」**＝感情（頑張った日のご褒美）。エモい・集客寄り。
- **B「オチは、牛タン定食」**＝日常あるある＋様式オチ。笑える・リーチ寄り。
- 2枚看板で「牛タン＝利久」を感情と日常の両面から積む。

### 3レイヤー運用
| レイヤー | 役割 | 例 |
|---|---|---|
| 旗艦 | 想起（CEP）を作る | ご褒美メシ／オチは牛タン定食 |
| リーチ機 | 発見・拡散 | 限界食べ・二択・ASMR・大盛り |
| 集客機 | 行きたい→探す | 炭火シズル・限定・こだわり・テールスープ |

### 制作ルール
- **やる**：強フック・独自資産固定・遅延型PR・オチ直前の無音→ジュッ・問いかけキャプション・ループ。
- **やらない**（`演出ガイドライン`）：食べ物を粗末にする奇行・レイジベイト・誤情報・実在地域/他者の中傷・偽表示・炎上ギミック。

## 5. KPIと測定（再生数の追いかけをやめる）
- フル視聴率 **7%以上**（今2.6%→回復が最優先）／保存率・コメント率／**プロフ閲覧率・指名検索%**／フォロワー/万リーチ。
- **来店（店舗アンケ「SNS見た？」＋「来る前どこと迷った？」）**＝効果を閉じる最重要ピース。遅行効果で見る。

## 6. 実行の優先順位
1. **投稿を再開・継続**（週3〜4本、止めない）
2. **独自資産を毎本固定**（今日から編集ルール）
3. **旗艦2シリーズ始動**（ご褒美メシ／オチは牛タン定食）
4. **フィジカル導線整備**（プロフ・店舗検索・テイクアウト）
5. **来店計測**（店舗アンケ）
6. **埋もれた良質動画を強フックで再編集・再投稿**（シチュー/ハラミ/肉厚牛たん）
