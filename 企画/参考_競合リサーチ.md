# 参考資料｜利久 競合リサーチ（戦略本体には含めない・内部メモ）

前提（シャープ／購買重複の法則）：同カテゴリーの顧客は複数ブランドを行き来する。競合は「牛タン専門」だけでなく、「牛タン＝ちょっと贅沢」で**機会と財布を奪い合う“ご褒美外食”全体**に広がる。以下は現時点のWebリサーチによる概観（店舗数は目安・要更新）。

---

## レイヤー1：牛タン専門の直接競合
| ブランド | 規模・エリア | 特徴 |
|---|---|---|
| **利久** | 約88店・**全国**（東名阪ふくむ） | 牛タン専門で**最大かつ唯一の全国チェーン** |
| ねぎし | 約42〜53店・**東京/神奈川中心** | 「牛タン・とろろ・麦めし」健康×日常ランチ。関東の日常想起が強い |
| 味の牛たん喜助 | 仙台発の老舗・首都圏にも／**EC強い** | 「仙台名物・伝統」の格。お取り寄せに強み |
| たんや善治郎 | 約15店・仙台/駅ナカ中心 | 仙台伝統・駅ナカ立地 |
| 牛タン焼専門店 司 | 宮城＋東京 | 1991年創業 |
| 陣中 | 仙台中心／**加工・お取り寄せ強い** | 牛タンシチュー等の加工品・ギフトに強み |
| 太助・味太助・旨味太助 ほか | 仙台ローカル多数 | 元祖系・観光名店 |

**読み取り**
- 直接競合の多くは**仙台ローカル**か**関東ローカル**。**全国で牛タン想起を取れるのは利久だけ**＝「牛タン＝利久」を全国で総取りしやすい。
- 関東は**ねぎし**が「日常ランチ×健康（麦とろ）」で強い→利久は正面衝突せず**“炭火の本物×ちょっと贅沢”**で場面をズラすのが得策。
- **EC・お取り寄せ**は喜助・陣中が先行→利久のテイクアウト/お取り寄せは**伸びしろ＆競合先行領域**。

## レイヤー2：「ご褒美外食」競合（機会・財布の奪い合い）
牛タン＝ちょっと贅沢なので、想起を奪い合う相手は牛タン店だけではない。
- **外食で食べたいものランキング**：1位 すし／2位 焼肉／3位 ハンバーガー（macaroni）。
- **“自分へのご褒美”外食の定番**：寿司・焼肉・和食・うなぎ・ステーキ（各種まとめ記事で共通）。

| ご褒美の競合カテゴリー | 代表例 | 利久との関係 |
|---|---|---|
| 焼肉 | 叙々苑（ランチ）、牛角、焼肉ライク | ご褒美肉の最強想起の一角。直接ライバル |
| 寿司 | 廻らない寿司、回転の上位皿 | ご褒美No.1想起。手強い |
| ステーキ | いきなり!ステーキ、ペッパーランチ | 「肉のご褒美」で重なる |
| うなぎ | 鰻専門・うな重 | ハレ・ご褒美の定番 |
| とんかつ | 和幸、まい泉、さぼてん | ちょっと贅沢な定食帯で重なる |
| プレミアム定食 | 大戸屋/やよい軒の上位、天ぷら | 日常寄りのご褒美で接触 |

**読み取り（利久の勝ち筋）**
- 「ご褒美＝寿司/焼肉」が強敵。利久はここに割って入るため、**牛タンならではの“手軽なご褒美”**を武器化：**予約不要・一人でも入れる・定食で完結・全国どこでも・テイクアウトでも**。＝“気軽に届く小さな贅沢”。
- つまり「叙々苑ほど構えないけど、牛丼より上」の**ちょうどいいご褒美**の第一想起を狙う（利久の価格・立地・気軽さが刺さる）。

## 測定を閉じる（購買重複を自社データ化）
- 利久客が「普段ご褒美に何を食べるか（寿司/焼肉/うなぎ…）」は自社では不明。
- **来店アンケに「ご褒美外食、普段は何を食べますか？」を1問**足すと、実際の競合（重複先）が見え、想起を奪う相手が特定できる。
