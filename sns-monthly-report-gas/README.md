# SNS月次レポート 自動化（Google Apps Script）v2

毎月の定例作業を仕組み化する GAS 一式です。GAS は **あなたのアカウント権限で動く**ため、
直接の書き込み（集約タブ・各プロジェクトシート）が可能です。

## できること

### ① 集計（完成・自動）
各社の **効果測定シート（投稿単位の生データ）** から対象月を集計し、コントロールSSの **「集約」タブ**へ出力。
- 指標：投稿数 / 再生数合計 / 再生平均 / EG率（=(いいね+コメント+シェア+保存)÷再生） / フォロワー増加 / プロフ閲覧計 ほか
- **アカウントハンドル照合**で別アカウント混入を⚠検知（出光⇄山謙のタブ混入事故対策）
- **データなし判定**、設定タブに行を足すだけで全クライアント拡張可

### ② 転記（各プロジェクトシートへ自動書き込み）
**「転記マップ」**に従って、各プロジェクトシートの当月「結果」セルへ集計値を書き込む。
- 月見出し（例 "5月"）と KPIラベルを**実行時にシート内検索**して位置特定（社ごとの座標を持たなくてOK）。
- **既定はDRY-RUN**（書かずに「どこへ何を書くか」をログ出力）。確認後に本番実行。

### ③ 当月ブロック点検
各プロジェクトシートに当月ブロック（"5月"見出し）が在るかを点検。無ければ「要追加」を通知。
※ブロックの自動挿入はレイアウト破損リスクが高いため、点検のみ（追加はテンプレ複製で運用）。

## セットアップ（初回のみ）

1. コントロール用スプレッドシートを用意（既に作成済みの「SNS月次レポート_自動化_設定」を利用可）。
2. タブを3つ用意：
   - **`設定`** … `設定_seed.csv` を貼り付け（A1から）
   - **`転記マップ`** … `転記マップ_seed.csv` を貼り付け（A1から）
   - （`集約`・`ログ`は実行時に自動生成）
3. `拡張機能 > Apps Script` → `コード.gs` を貼り付けて保存 → スプレッドシートをリロード。
4. メニュー **「SNS月次集計」** が表示される。

## 毎月の運用フロー

1. **① 前月を集計**（or 対象月を指定）→ `集約`タブで全社の数値と⚠警告を確認。
2. **③ 当月ブロック点検** → 「要追加」の社はテンプレ複製で当月ブロックを追加。
3. **② 転記プレビュー（DRY-RUN）** → `ログ`タブで「どのシートのどのセルへ何を書くか」を確認。
4. 問題なければ **②’ 転記を実行（本番）**。

> 🔰 **初回は必ず1社で検証**：`設定`タブで1社だけ `有効=TRUE` にして DRY-RUN → 本番 →
> 実際のセルに正しく入ったか目視。OKなら他社も `有効=TRUE` に。

## 「設定」タブ 列仕様

`有効 / クライアント名 / 効果測定シートID / 生データタブ名 / プロジェクトシートID / アカウント`
- `生データタブ名`：空欄で自動検出。
- `アカウント`：`@`無しハンドル（照合用。空欄で照合スキップ）。

## 「転記マップ」タブ 列仕様

`クライアント名 / KPIラベル / 指標キー / 対象`
- `クライアント名`：`設定`と同名。`*` は「個別指定の無い全社」に適用（**個別行がある社は個別行のみ採用＝マージしない**ので、その社で使う行は全部書く）。
- `KPIラベル`：プロジェクトシート上のKPI表記。正規表現可（例 `再生数|平均再生`）。
- `指標キー`：下表から選ぶ。
- `対象`：通常 `結果`。

### 指標キー一覧

| 指標キー | 内容 |
|---|---|
| `posts` | 投稿数 |
| `views_sum` | 再生数合計 |
| `views_avg` | 再生平均/本 |
| `eg` | EG率%（(いいね+コメント+シェア+保存)÷再生） |
| `follow_add` | フォロワー増加 |
| `profile_sum` | プロフィール閲覧 合計 |
| `reach_sum` | リーチ 合計 |
| `fullview_avg` | フル視聴率 平均%（生データが小数0.03=3%前提で%換算） |
| `watch_avg` | 平均視聴時間 平均（秒） |

> 来院数・予約数・問い合わせ数・リンククリック数など**オフライン/外部計測のKPIは効果測定シートに無い**ため自動転記対象外（手入力）。

## 重要な注意 / 既知の制約

- **本番書き込み前に必ずDRY-RUNでログ確認**。GASはこの開発環境では実行テストできていないため、
  初回は1社で「狙ったセルに入るか」を必ず目視検証してから全社展開してください。
- 月ブロックが「同一シート内に複数（例：通常ブロックと『▪️0X月次』ブロック）」ある場合、
  最初に見つかった `"5月"` 見出しの月グループに書き込みます。意図と違う場合は
  `転記マップ` のラベルを具体化するか、対象ブロックを1つに整理してください。
- `fullview_avg` は生データのフル視聴率が小数（0.03=3%）である前提。％表記で入っている社は調整要。
- **出光**：実数は外部「簡単DC」にあり効果測定シート(222)へ未取込（かつ山謙タブ混入）。
  簡単DCのデータがシートに入り次第、`設定`で `生データタブ名` を指定し `有効=TRUE`。
- **さくらフォレスト / しろくま電力**：当月の生データが無いため `有効=FALSE`。
