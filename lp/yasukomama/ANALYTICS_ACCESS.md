## 0. 付与の実行可否（重要）

| 操作 | 自動実行 | 理由 |
|---|:-:|---|
| GA4へのユーザー追加 | **不可** | この環境にGoogle Analytics Admin API／操作ツールが無い |
| Driveファイルの共有追加 | **不可** | Drive権限ツールは閲覧(get_file_permissions)のみ。付与(create permission)ツールが無い |

→ **付与そのものは下記「人間が2分で実施する手順」で対応。** 本書はその台帳＋手順書。

## 2. 権限付与手順（GA4）｜人間が2分で実施

1. [analytics.google.com](https://analytics.google.com/) に**管理者アカウント**でログイン
2. 左下 **管理（歯車）→ プロパティ列 → プロパティのアクセス管理**
3. 右上 **「＋」→ ユーザーを追加**
4. メールを入力し、ロールを選択（複数まとめて可）
   - `y-minami@tre-pro.co.jp` → **管理者**
   - `yuuri.minami@tlpc-t.co.jp` → **編集者**
   - `tsp@tre-pro.co.jp` → **アナリスト**
5. 「新規ユーザーにメールで通知する」ON → **追加**

## 3. 権限削除手順

1. **管理 → プロパティのアクセス管理**
2. 対象ユーザー行の右「︙」→ **アクセス権を削除**
3. 退職・契約終了時は即時実施。**管理者は最低2名**残す（ロックアウト防止）

## 4. 緊急対応手順

| 事象 | 対応 |
|---|---|
| 不正アクセス疑い | 該当ユーザーを即削除 → 全管理者のパスワード/2段階認証を確認 |
| 管理者が誰もいない | Googleアカウントのオーナー（プロパティ作成者）から再付与 |
| 測定停止/数値異常 | `LP_CONFIG.GA_ID` の値、DebugViewでの発火、タグ読込（Network）を確認 |
| データ消失防止 | BigQueryエクスポート or 月次で主要指標を効果測定シートへ転記 |

## 4. Drive（効果測定シート／アカウント管理シート）共有

採用ファネル「応募〜採用」はシート側管理のため、同3アドレスにDrive共有も揃える。
- 対象：`【044_株式会社TOWA/恭子ママ】効果測定シートv3`、`同 アカウント管理シート`
- 手順：各シート右上 **共有** → 3アドレス追加 → 役割（管理者=編集者／TSP=閲覧者）を付与
