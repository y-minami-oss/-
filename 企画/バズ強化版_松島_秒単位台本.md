# バズ強化版｜松島海岸駅前店 秒単位台本

バズ法則を適用しつつ、利久のブランド信頼（本物感）を守る形に調整。
共通の強化ルール＋拡散の中心2本（動画7・動画4）の秒単位台本。

## 共通ルール（バズ強化アップデート）
- **ウロボロス（無限ループ）**：最後のセリフ/音を冒頭1秒目とシームレスに繋ぐ（例「…って思うでしょ?」→冒頭へ）。2周・3周させ完了率を上げる。
- **具体的な数字**：「せんべい3種」→「直径◯cmの大判せんべい」、「団子6種」→「累計◯本売れた団子」。※実数のみ・要事実確認。
- **キャプション1行目は質問**：「Q. 団子に◯◯、ぶっちゃけアリ?」
- **ピン留めコメント**：投稿直後に公式/萌江さんから「私はナシ派なんだけど、みんなは?笑」を固定→返信ツリーが伸びる。
- **秒数・答え・店名は最後**。冒頭は説明でなく“違和感・問い・強い音”。

# 第2弾フィードバック反映（安全版）

## 共通ルール 追加
- **高速カット基準**：1カット=**1.5〜2秒**を目安に画角を切替（寄り→引き→対象違い→表情）。40秒なら約20〜25カット。会話はダラダラ映さず、咀嚼顔・脂のクローズアップ・ツッコミ顔を高速で回す。
- **違和感フック（安全版）**：冒頭3秒は“予想外だが不快でない”絵に。食べ物を粗末にする奇行（おでこで割る/アイマスク等）は**不採用**（老舗ブランドを損なう）。代わりに「真顔ドアップ→巨大せんべいがヌッと侵入」など。
- **ツッコミ余白（安全版）**：本筋と無関係な“隙”を1箇所だけ。**店の信用を傷つけない範囲**で（変な箸の持ち方／黒板のわざと誤字／牛たんの被り物）。※偽のぼったくり価格・不衛生表現はデマ拡散・信用毀損リスクのため**禁止**。
- **ウロボロス**：ラストのセリフ/音を冒頭1秒目に繋ぐ。全本標準装備。
