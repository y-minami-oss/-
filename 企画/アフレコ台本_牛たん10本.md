# 1. この企画の狙い

## なぜアフレコか

| 課題 | アフレコで解決すること |
|---|---|
|**尺が守られない**（台本15〜30秒想定→実際53〜112秒）|**ナレーション原稿の文字数で尺が決まる**。45秒分しか書かなければ45秒で終わる|
|冒頭が弱い|現場の成り行きでなく、**最初の一言を設計できる**|
|撮影時間の制約|**演者が喋らないので画だけでよい**|
|お酒の映り込みを減らしたい|**画をこちらで選べる**|
|大食い企画のリスク|食べる量に依存しない企画が作れる|
|**過去素材が活用できる**|**撮影ゼロでも制作可能な本数がある**|

## 方針

- **全10本を牛たん軸**で構成（10/16合意の「牛たん7割」を上回る配分）
- **全本30〜45秒**（2026年データで0〜40秒のフル視聴率4.22%／70秒超2.38%）
- ナレーションは**落ち着いた説明調**。煽らない。断定で終える

# 2. 設計の根拠

## 自社データ（利久210本・キャプションの型別）

| 型 | 本数 | 再生中央値 | 最大 |
|---|---:|---:|---:|
|**「実は」「秘密」「公開」**|8|**17,804**|95,978|
|問いかけなし（断定・感嘆）|130|6,478|2,443,007|
|二択（どっち派）|14|5,938|65,835|
|問いかけあり（全体）|80|**2,920**|913,911|
|「何口」型|7|3,081|28,578|

**読み取れること**
1. **「実は・秘密・公開」が突出**（他の3倍）
2. **単純な問いかけは弱い**。「〜と思いますか？」だけでは機能しない
3. 二択は問いかけの中では強い
4. 過去最大913,911回は「焼長なら音だけで美味しい牛たんが焼ける！？」＝**驚きの断定**

## 冒頭の基本式

> **異常・損失・対立を先出し → 誰の問題か確定 → 未決済の問いを残す**

### 0〜10秒の配置

| 秒 | やること |
|---|---|
|**0-3**|結果／損失／異常／証拠／強い反応のいずれか1つ|
|**3-7**|状況を理解させる（誰の問題か、何を失うか）|
|**7-10**|最初の仮説を作らせる|

### 利久版の最強型

> **取り返しのつかない結果を見せる → 失敗できない理由を言う → 責任を特定させない**

|  | 構造 | 利久版（台本①） |
|---|---|---|
|結果|取り返しのつかない状態|縮んで反り返った牛たん|
|損失|失敗できない理由|「お土産で買ってきた、最後の一枚でした」|
|判断余地|責任を特定させない|「肉が悪いわけじゃありません」|

# 4. ナレーション台本 全文

## ① 家で焼く牛たん、失敗の原因は焼く前にある
**45秒／213字**

```
0-3    これ、家で焼いた牛たんです。
3-7    お土産で買ってきた、最後の一枚でした。
7-11   肉が悪いわけじゃありません。焼く前に、決まっていました。
11-19  一つ目。焼く15分前に、冷蔵庫から出しておく。
       これだけで、火の通り方が変わります。
19-26  二つ目。油は、ひきません。
       牛たん自体の脂だけで、十分に焼けます。
26-35  三つ目。焼けても、すぐ切らない。
       余熱で15秒。肉汁が、中心に戻ります。
35-45  ここまでやれば、家でもかなり近づきます。
       ただ、炭火の香りだけは、どうしても出せません。
```

3-7    牛たん定食には、順番があります。

12-18  牛たんの脂を受け止める準備が、ここでできます。
18-23  そしてもう一つ。そのまま飲む人が、多すぎます。

28-33  そして、コショウをひと振り。味が、締まります。

# 8. 運用ルール

## 全編共通

| 項目 | 設定 |
|---|---|
|**ナレーション**|落ち着いた説明調。煽らない。断定で終える|
|**冒頭0.5秒**|必ず音を入れる（無音・暗転スタートはしない）|
|**テロップ**|音を消しても意味が通るように。ただし読まないと分からない作りにはしない|
|**お酒**|全編で映さない（アカウント評価への影響を避けるため）|
|**締め**|店舗情報は最後の2秒。ロゴ＋「牛たん炭焼 利久」|
|**尺**|**30〜45秒を厳守**。超える場合は2本に割る|

## 冒頭でやらないこと

- 店舗外観から始める
- 自己紹介・挨拶
- 「今日は◯◯を紹介します」
- 長い前提説明
- 問いだけ投げて事実を見せない
- **架空のクレーム・揉め事を作る**
- **根拠のない健康訴求**
- **他店・他ブランドを引き合いに出す**

## 冒頭チェックリスト

|  | 項目 |
|---|---|
|1|無音でも「異常」が分かるか|
|2|3秒以内に、困っているのが**視聴者自身**だと分かるか|
|3|何を失うか分かるか|
|4|視聴者の頭に問いが生まれるか|
|5|一文で状況を説明できるか|
|6|続きを見れば答えが返ると期待できるか|
|7|本編が冒頭の約束を回収しているか|
|8|煽りだけに依存していないか|
|9|作り話の対立を入れていないか|
|10|事実と違うことを言っていないか|

# 付録：読み上げ速度の調整

現在は**1秒あたり5文字**で統一しています。

| 読み手 | 目安 | 調整 |
|---|---|---|
|ゆっくり|4字/秒|各本から20〜40字削る|
|**標準（現状）**|**5字/秒**|**そのまま**|
|速め|6字/秒|各本に10〜20字足せる|

読み上げ担当が決まり次第、その方の速度に合わせて文字数を再調整します。
