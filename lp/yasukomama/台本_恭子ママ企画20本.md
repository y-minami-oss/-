# 恭子ママ TikTok企画 台本 20本（ストーリー設計版 v2）

**設計思想（台本チェックリスト準拠）**
- 「情報・トピック」ではなく **一人の人物の“感情の旅”** を描く。組織の論理（理念説明）は、個人の物語の“裏”に隠す。
- **3秒で感情を掴む**：説明から入らない。ビジュアルフック＋“続きが見たくなる予兆/問い”。
- 構成は **Hook → Setup（共感・Before）→ Conflict（But-So）→ Twist/Climax（Before→After）→ Resolution＋最後のひとひねり → CTA**。
- CTAは温度を下げない。セールスでなく「気になった子へ」の余白で。
- **翻訳フレーム**：抽象価値→構造→行動→感情→**記憶に残る情景**へ落とす。
- **体温**：手ブレ・息遣い・沈黙・赤い目・アドリブを残す。完璧さより誠実さ。

## ◆ Aブロック｜トラブルの中で“人”が動く物語

### 01｜酔って絡むお客様に、新人が困った…ママはどう収める？
**主人公の旅：** 新人＝「怖い・逃げたい」→「ここなら守ってもらえる」。視点は**新人**に固定（ママ目線で語らない）。
**翻訳：** 安心 → “守る店” → ママが間に入る → 不安が抜ける → **新人の肩の力がふっと抜ける表情**
- **Hook(0-3秒)**：手ブレ気味の主観カット。テロップ「入店3日目。お客様の手が、私の腕を掴んだ」（無音でも伝わる緊迫）
- **Setup**：声が出せず固まる新人の表情アップ。周りはざわつくだけ。
- **Conflict(But-So)**：助けを呼びたい、でも“迷惑かも”と言えない → さらに強く絡まれる
- **Twist**：視界にママの手。すっと間に入り、客には笑顔、新人には小声で「呼んでくれてありがとうな」
- **Resolution＋ひとひねり**：新人がほっと涙。ママ「叱るわけないやろ。一人で抱えた時点で、私の負けや」
- **CTA**：テロップ「“ママ呼んで”が言える店です」／プロフのLINEから、不安なこと聞いてね
- **体温メモ**：新人の震える声・沈黙の2秒をカットしない。台本通りに喋らせず半アドリブで。

### 02｜支払いが滞ったお客様への、角を立てない伝え方
**主人公の旅：** キャスト＝「言いにくい・自分のせい？」→「ママが背負ってくれた」安堵。
**翻訳：** 信頼 → “言いにくいことは店が持つ” → ママが“心配”として連絡 → 罪悪感が消える → **キャストが胸をなで下ろす横顔**
- **Hook**：スマホ画面のアップ、未入金の通知。テロップ「『お金返して』を、一度も言わずに回収した話」
- **Setup**：キャストが小声で「私が言わなきゃですよね…」と落ち込む
- **Conflict(But-So)**：催促すれば関係も売上も終わる、でも放置もできない
- **Twist**：ママがスマホを取り「ここから先は私の仕事」。送る文面「最近顔見てへんから心配で」——お金の話は一言も無い
- **Resolution＋ひとひねり**：後日、客が来店。ママ「催促した瞬間に終わるんよ。これは“取り立て”ちゃう、“心配”や」
- **CTA**：テロップ「面倒は、ママが持ちます」／LINEへ
- **体温メモ**：実際のLINE文面を手元撮り。打ちながらの少しの沈黙を残す。

### 03｜他店からの引き抜きの電話に、ママの大人な対応
**主人公の旅：** ママ＝怒り→誇り。視聴者は「人として扱われる店だ」と感じる。
**翻訳：** 尊重 → “キャストは商品じゃない” → 値踏みの電話を断る → 静かな怒り→誇り → **電話を置いた後の、少し笑う横顔**
- **Hook**：鳴る店の電話。テロップ「『その子、いくらで譲ってくれる?』」
- **Setup**：受話器越しの値踏み。ママの表情がすっと冷える
- **Conflict(But-So)**：相手は条件を上げてくる、でもママは一切乗らない
- **Twist**：「うちの子は商品ちゃうので」と静かに切る。荒げない
- **Resolution＋ひとひねり**：少し笑って「…でも、引き抜きたなるほど育ってるってことやんな。そこは誇りや」
- **CTA**：テロップ「人として扱う店です」／LINEへ
- **体温メモ**：電話の相手の声は入れず、ママの表情の変化だけで見せる。

### 04｜ドタキャンが続くお客様、繋ぐか見送るかママの判断
**主人公の旅：** ママ＝葛藤（売上 vs キャストの時間）→決断。
**翻訳：** キャストファースト → “時間を守る” → 太客でも切る → 迷い→覚悟 → **空けて待っていた席のキャストの寂しげな背中**
- **Hook**：予約席のプレート。テロップ「太いお客様。でも私は“切る”と決めた」
- **Setup**：3回目のドタキャン。準備して待っていたキャストの落ちた表情
- **Conflict(But-So)**：売上は欲しい、でもその度にうちの子の時間が捨てられる
- **Twist**：ママが静かに予約名簿から線を引く
- **Resolution＋ひとひねり**：「お金は大事。でもうちの子の“待つ気持ち”のほうが高い。それ守れんママに、人は預けられへん」
- **CTA**：テロップ「キャストの時間を守る店」／LINEへ
- **体温メモ**：待つキャストの所在なさげな手元・時計を見る仕草を生で。

### 05｜閉店後のトラブルも、誰も傷つけずに解決するお店の対応
**主人公の旅：** 視聴者＝「見えない部分も安心」。閉店後の“裏側”という非日常を覗かせる好奇心フック。
**翻訳：** 安心 → “裏方が整っている” → 怒鳴らず解決 → 緊張→安堵 → **明かりを落とした静かな店内**
- **Hook**：消えていく店の照明。テロップ「お店が本当に試されるのは、閉店した後」
- **Setup**：客同士の小競り合い／送りの段取り／忘れ物——閉店後に起きるリアル
- **Conflict(But-So)**：誰かのミスにしたら早い、でもそれをやると人が辞める
- **Twist**：ママが一つずつ、誰も責めずに片付けていく
- **Resolution＋ひとひねり**：「怒鳴って解決したこと、一回もない。裏がちゃんとしてる店は、表で安心して笑える」
- **CTA**：テロップ「見えない所まで整えてます」／LINEへ
- **体温メモ**：手持ちカメラで“ドキュメント感”。生活音（椅子を上げる音等）を残す。

### 06｜一線を越えたお客様に、ママがきっぱり伝えた一言
**主人公の旅：** キャスト＝恐怖→「守られた」安心。安全面の不安に直球。
**翻訳：** 安全 → “線を引く” → 太客でも出禁 → 恐怖→守られた感 → **ママの背中に隠れるキャストの手**
- **Hook**：強引に伸びる客の手、固まるキャスト。テロップ「うちの子に触れた瞬間、お客様でも切る」
- **Setup**：常連で、店に長く落としてきた“太客”という前提
- **Conflict(But-So)**：切れば売上を失う、でも見過ごせば子が傷つく
- **Twist**：ママが静かに前へ。「うちの大事な子です。お引き取りください」
- **Resolution＋ひとひねり**：去る客。ママ「売上一人分より、うちの子の安全。比べるまでもない」
- **CTA**：テロップ「線引きできる店です」／LINEへ
- **体温メモ**：声を荒げない。低く静かなトーンほど怖さと信頼が出る。

### 07｜新人を下に見る空気を、ママがその場で正す
**主人公の旅：** 新人＝「居場所がない」→「ここにいていい」。人間関係の不安に直球。
**翻訳：** 居場所 → “序列で回さない” → その場で空気を正す → 萎縮→安心 → **新人がやっと顔を上げる瞬間**
- **Hook**：新人にだけ素っ気ない先輩。テロップ「先輩が新人に冷たい。私はその場で止めた」
- **Setup**：俯いて声も出せない新人、見て見ぬふりの空気
- **Conflict(But-So)**：後で個別に言えば角は立たない、でもその数分で新人の心は折れる
- **Twist**：ママがその場で「あの子もできひん時あったやろ?」
- **Resolution＋ひとひねり**：空気が緩む。「序列で回す店は、新人がすぐ消える。だから空気は私が作る」
- **CTA**：テロップ「先輩も後輩もない店」／LINEへ
- **体温メモ**：新人の安堵の小さな笑みを、引きの画でさりげなく。

### 08｜クレームのお客様を、ママが常連さんに変えるまで
**主人公の旅：** 視聴者＝「ここで接客を学べる」。怒り→信頼の逆転で最後まで見せる。
**翻訳：** 成長環境 → “クレームは伸びしろ” → 言い訳せず謝る → 不信→信頼 → **怒って帰った人が、笑って暖簾をくぐる**
- **Hook**：席を立つ怒った客の背中。テロップ「『二度と来ない』と帰った人が、今は週1の常連」
- **Setup**：クレーム対応に固まる新人。場の温度が下がる
- **Conflict(But-So)**：言い訳すれば自分は守れる、でも関係は終わる
- **Twist**：ママは理由を聞かず、まず「不快にさせて、ごめんなさい」だけ
- **Resolution＋ひとひねり**：常連になった客の今。「クレームは“もっと良くして”のサイン。この考え方、うちの子に全部教えてる」
- **CTA**：テロップ「接客、ちゃんと学べます」／LINEへ
- **体温メモ**：再現の客役は派手に怒らせず、リアルな“静かな不満”で。

## ◆ Bブロック｜“人柄”が伝わる物語（理念は個人の話に溶かす）

### 09｜「うちの子を守る」キャストを大切にするママの姿勢 ＜ピン留め候補＞
**主人公の旅：** ママの原点（過去の後悔）→今の信念。理念を“説明”せず“物語”で語る。
**翻訳：** 理念 → “うちの子を守る” → 売上よりキャスト → 過去の悔い→決意 → **昔の自分の写真を見るママの目**
- **Hook**：ママが一枚の古い写真を手に。テロップ「私が店で一番大事にしてること、理由があります」
- **Setup**：「昔、私を守ってくれるママはいなかった」——自身がキャスト時代に傷ついた過去
- **Conflict(But-So)**：売上を追えば店は回る、でもそれだと“あの頃の私”を増やすだけ
- **Twist**：「だから決めた。お客様より先に、うちの子を守るって」
- **Resolution＋ひとひねり**：「『この店来てよかった』。それ言わせられへんママに、人は預けられへんやろ」
- **CTA**：テロップ「ここで働くって、こういうこと」／プロフのLINEから話そう
- **体温メモ**：作り込みすぎない。言葉に詰まる数秒・潤む目をそのまま残す。

### 18｜辞めようとした新人が残った理由（お店のサポート体制）
**主人公の旅：** 新人＝挫折→再起。本人の口から語らせる密着。
**翻訳：** 定着 → “一人にしない” → ママが追いかける → 諦め→希望 → **初指名の伝票を握りしめる手**
- **Hook**：スマホに残る退職LINE。テロップ「『もう無理です』——あの子から、そう来た夜の話」
- **Setup**：本人インタビュー「指名取れなくて、自分だけ向いてないと思って…」（少し声が震える）
- **Conflict(But-So)**：辞めさせれば楽、でもママは「向いてないんちゃう、やり方知らんだけ」と追いかけた
- **Twist**：付きっきりの同席・振り返り → 初指名の夜
- **Resolution＋ひとひねり**：本人「あの時ママが追いかけてくれたから、今がある」涙
- **CTA**：テロップ「一人にしない店」／LINEへ
- **体温メモ**：質問は感情(E)中心で。「その時、何を感じた?」「何が頭をよぎった?」沈黙を待つ。

### 19｜ラウンジ永遠のリアルな働き方を、恭子ママが正直にお話しします
**主人公の旅：** 視聴者の本音「どうせ良いことしか言わない」を冒頭で代弁→裏切る誠実さ。
**翻訳：** 信頼 → “盛らない” → 都合の悪いことも言う → 警戒→信頼 → **目を逸らさず話すママの正面**
- **Hook**：ママ正面、無編集風。テロップ「良いことばっかり言う店、逆に怪しいでしょ」
- **Setup**：「楽して稼げるとは言わへん。最初は緊張するし、合わへん日もある」
- **Conflict(But-So)**：盛れば応募は増える、でもミスマッチで辞める子が増えるだけ
- **Twist**：「でも、やり方はちゃんと教える。無理もさせへん。だから続く子が多い」
- **Resolution＋ひとひねり**：「飾らんと正直に言える店を、選んでほしい」
- **CTA**：テロップ「リアルが知りたい子へ」／LINEで何でも聞いて
- **体温メモ**：ワンカット・最小編集。言い淀みもそのまま＝誠実さの記号。

### 20｜「こんな方と働きたい」恭子ママが伝える、お店が求める人柄
**主人公の旅：** 未経験者の「自分なんて」→「私でもいい」。
**翻訳：** 採用基準 → “顔より素直さ” → 技術は教える → 引け目→希望 → **ノーメイクで面接に来た子を見るママの笑顔**
- **Hook**：テロップ「うちが採るのは、可愛い子ちゃう」（容姿不安を一発で外す）
- **Setup**：「顔は関係ない。挨拶ができて、素直で、人を大事にできる子」
- **Conflict(But-So)**：華やかさで選べば早い、でもそれだと続かないし伸びない
- **Twist**：「技術は教えられる。でも“素直さ”だけは持ってきてほしい」
- **Resolution＋ひとひねり**：「未経験、大歓迎。むしろまっさらな子のほうが伸びる」
- **CTA**：テロップ「当てはまった子、待ってます」／プロフのLINEへ
- **体温メモ**：ママの実際の口癖・笑い方を活かす。台本臭さを消す。

## ◆ Cブロック｜ノウハウも“一人の子の物語”で見せる

### 10｜なかなか伸びない子に共通する3つのこと
**主人公の旅：** 視聴者＝「ドキッ→直せる希望」。保存される実用＋愛のある締め。
**翻訳：** 成長 → “才能でなく習慣” → 3つを直す → 焦り→安心 → **メモを取り始めるキャストの手**
- **Hook**：テロップ「伸びひん子、だいたいこの3つ。当てはまったら今日で終わりにしよ」
- **Setup**：「才能の差やと思ってる子、多いけど」
- **Conflict(But-So)**：①お礼の連絡が遅い ②“指名ない”を環境のせいにする ③人の売れ方を見てない（But-Soで一つずつ深掘り）
- **Twist**：「全部、才能ちゃう。今日から直せることだけ」
- **Resolution＋ひとひねり**：「ダメ出しに聞こえた? 違う。伸びてほしいから言うてるんよ」
- **CTA**：テロップ「ちゃんと教える店」／LINEへ
- **体温メモ**：①②③はテロップで（無音保存対応）。締めはあくまで温かく。

### 11｜指名され続ける子がしている、見た目以外の努力
**主人公の旅：** 容姿に自信のない視聴者＝「私にもできる」。
**翻訳：** 再現性 → “記憶の接客” → 全部覚える → 諦め→希望 → **前回の話を覚えていて、客がはっとする瞬間**
- **Hook**：テロップ「ずっと指名される子、実は美人とは限らへん」
- **Setup**：「派手でもないのに、なんであの子だけ?」という疑問
- **Conflict(But-So)**：可愛さでは勝てない、でも勝ってる理由がある
- **Twist**：種明かし——「お客様の話を、前回の分まで全部覚えてる」
- **Resolution＋ひとひねり**：「特別扱いされたい人に、特別な記憶を返す。顔ちゃう、努力。だから誰でもできる」
- **CTA**：テロップ「やり方、教えます」／LINEへ
- **体温メモ**：再現で“覚えてた一言”に客が動く瞬間をリアルに。

### 12｜入店して最初の1ヶ月でやるべきこと・避けたいこと
**主人公の旅：** 応募直前の不安「何すれば」→「これならやれそう」。
**翻訳：** 安心 → “最初の1ヶ月の地図” → やる/避けるが明確 → 不安→自信 → **チェックリストを見て頷く新人**
- **Hook**：テロップ「最初の1ヶ月で、その後の9割が決まる」
- **Setup**：右も左も分からない初出勤の不安を代弁
- **Conflict(But-So)**：背伸びしたくなる、でも無理キャラは続かない
- **Twist**：やる＝全員に挨拶／すぐ聞く／先輩を見る ⇔ 避ける＝比べて凹む／一人で抱える
- **Resolution＋ひとひねり**：「最初はできひんで当たり前。“聞ける子”が一番伸びる」
- **CTA**：テロップ「1ヶ月、隣で見てます」／LINEへ
- **体温メモ**：やる/避けるは図解テロップで保存特化。

### 13｜太って見えないドレスの選び方
**主人公の旅：** 容姿コンプ→「自信ないままでいい」。実用バズ＋心理障壁の解除。
**翻訳：** 自己肯定 → “見せ方の技術” → ドレス3原則 → 引け目→自信 → **鏡の前で姿勢が変わる瞬間**
- **Hook**：同じ子のNG/OK着比べを一瞬カットイン。テロップ「同じ体型でも、ドレスで別人になる」
- **Setup**：「痩せなきゃ…」と鏡の前で落ち込むあるある
- **Conflict(But-So)**：体型は急に変わらない、でも“見え方”は今日変えられる
- **Twist**：3原則実演（ウエスト位置・色・首元）でビフォーアフター
- **Resolution＋ひとひねり**：「痩せる必要ない。“見せ方”を知るだけ。それも入ったら全部教える」
- **CTA**：テロップ「自信ないままで大丈夫」／LINEへ
- **体温メモ**：実在キャストで実演。完璧な細さでなく等身大の子で。

### 14｜指名がない日こそやっておきたい、次に繋がる行動
**主人公の旅：** 指名ゼロで凹む子→「無駄じゃなかった」。メンタルケア型指導。
**翻訳：** 前向き → “暇な日＝種まき” → ヘルプ席を未来の指名に → 落胆→希望 → **暇な日に丁寧に接客し、後日その客が指名してくる**
- **Hook**：テロップ「指名ゼロの日、落ち込むのはもったいない」
- **Setup**：誰にも呼ばれず、スマホを見て時間を潰す夜
- **Conflict(But-So)**：今日は無駄に思える、でも“今”が来月を作る
- **Twist**：ヘルプで入った席を丁寧に → 後日その客が「君を指名で」
- **Resolution＋ひとひねり**：「ゼロの日は、種まきの日や」
- **CTA**：テロップ「考え方から育てます」／LINEへ
- **体温メモ**：凹む夜の表情を丁寧に。希望への転換を“後日カット”で見せる。

## ◆ Dブロック｜密着（“ドラマ”でなく“変化”を撮る）
※BeforeとAfterの対比を構成で明確に。インタビューは感情(E)質問中心、沈黙を恐れない。

### 15｜〜から転職、新人の初出勤に密着
**主人公の旅：** 前職を辞めた子＝「私なんかが」→「明日も来ます」。同じ境遇に刺さる。
**翻訳：** 一歩 → “初日も一人にしない” → ママが横でフォロー → 不安→達成感 → **帰り道、ふっと笑う初出勤の顔**
- **Hook**：私服で店の前に立つ後ろ姿。テロップ「元◯◯。今日が、人生初の夜の仕事」
- **Setup**：控室で声が小さい・手が震える本人インタビュー
- **Conflict(But-So)**：「無理かも」と泣きそう、でもママが一つずつ隣で
- **Twist**：初めてお客様に笑ってもらえた瞬間
- **Resolution＋ひとひねり**：帰り際「正直、来る前は怖かった。でも…明日も来ます」
- **CTA**：テロップ「初日から、一人にしません」／LINEへ
- **体温メモ**：手ブレ・控室の沈黙・震える声を残す。ナレで肩書きは後から補う。

### 16｜未経験で入って3ヶ月、あの子はこう変わりました
**主人公の旅：** 「挨拶もできなかった子」→「見捨てられなかったから変われた」。
**翻訳：** 育成力 → “3ヶ月の伴走” → Before/After対比 → 自信のなさ→誇り → **入店時と今の接客を並べた瞬間**
- **Hook**：入店初日の硬い映像。テロップ「3ヶ月前、挨拶もできひんかったこの子が」
- **Setup**：当時の本人の不器用さ（実映像）
- **Conflict(But-So)**：何度も心折れかけた、でも誰も見捨てなかった
- **Twist**：今の堂々とした接客映像へカット切り替え（明確なBefore→After）
- **Resolution＋ひとひねり**：本人「変われたのは、ダメな時も見捨てられなかったから」
- **CTA**：テロップ「あなたの3ヶ月後を、見にきて」／LINEへ
- **体温メモ**：過去映像は粗くてOK＝リアルさ。対比は説明せず映像で語らせる。

### 17｜目立たなかった子が売れっ子になるまで
**主人公の旅：** 端の席だった子→指名トップ。「派手で勝てないなら誠実さで」逆転劇。
**翻訳：** 希望 → “主役は入れ替わる” → 誠実な努力 → 劣等感→確信 → **かつて端だった子が、今は真ん中の席に**
- **Hook**：テロップ「正直、最初は誰も注目してなかった、この子の話」
- **Setup**：いつも端の席、ヘルプばかりだった頃の本人
- **Conflict(But-So)**：派手な子に埋もれる、でも諦めず“覚える接客”を磨いた
- **Twist**：今は指名トップ常連。本人「派手さで勝てへんなら、誠実さで勝つって決めた」
- **Resolution＋ひとひねり**：ママ「主役はいつでも入れ替わる。うちはそういう店や」
- **CTA**：テロップ「次は、あなたかも」／LINEへ
- **体温メモ**：本人の言葉を編集で整えすぎない。言い切る瞬間の表情を主役に。
