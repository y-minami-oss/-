## A. ファネルを分解して「どこで負けたか」を特定する

**実データ（YouTube経由・約半年間）:**
```
応募 22件
 └ 有効応募（採用ターゲット）12名   ← 除外理由：年齢が高すぎ／海外在住
    └ 一次選考 実施 10名            ← 応募→一次の歩留まりが非常に高い
       └ 一次合格 5名（通過率50%）
          └ 適性検査で1名不合格
             └ 最終選考 4名
                └ 内定 2名（不採用2名）
                   └ 内定辞退 2名  ← 🔴 ここで全損
```

### 🔴 分析から出た結論
- **応募の「質」は他媒体より高い**
  > 「他の媒体や人材紹介だと**費用がかかっているので一次選考が厳しめ**になっちゃうんですけど、SNSはどんどん上げていこうという方針。それで（通過率が）高くなっている」
  → 通過率の高さには**運用方針バイアス**も混じっていることを正直に認識している
- **負けているのは最終フェーズ（クロージング）**
  > 「応募まで来ているけど採用にならない。**採用まで本当にあと1本**みたいな感じですね」

### 一次選考の合否基準（＝コンテンツで狙うべき人物像の定義）
| 落ちた理由 | 通った理由 |
|---|---|
| 暗い | **第一印象のパワー** |
| 26歳で転職3回以上 | **自分で自分のことを話す力（自己開示力）** |
| （＝活躍できなそう／離職しそう） | 初対面での**明るさ・快活さ** |
| | 🔴 **覚悟が決まっている**（社長の動画を結構見てきてくれる方が多いので） |

> 「**LINE登録から選考に進んで一次合格した方は、本当に全員採用したかった**」

### 内定辞退2件の敗因分析
| 事例 | 敗因 |
|---|---|
| ① 転職回数の多い候補者 | 社長が最終面接で「10年くらい働く気合いでやらないとダメだよ」と**何度もきつく伝えた** → 最後に覚悟を決めきれなかった |
| ② 東急リバブルに流出 | 競合の採用担当が「**お客様のためになることは何でもしていいよ**」と伝えた。候補者の就活軸（お客様のため）に**寄り添った** → 「採用担当がうまかった」 |

**この振り返りの受け止め方（重要）:**
- クライアント側「これは**私たちの失敗**です。すいません」と自己開示
- クリエイティブ責任者「でも**伝えないと結局離職になっちゃう**というところですよね、きっと」
  → 相手の判断を責めず、トレードオフとして受け止め直す

## B. 🔴 「入社決定プロセスの逆算」フレーム（最重要の企画メソッド）

### 考え方
> 「**今、働いて定着しているところから逆算**してやりたい。
> 今の発信でもいいオーバー（応募）は集まっていると思うので、より**ミスマッチをなくす**」
> 「**今働いている人たちの統計や共通点を見つけて**、その人たちに近い人たちが、どういうところだったら興味を持ってくれるか」

### 求職者の3フェーズ × フェーズ別コンテンツ
```
【知る】     まだ会社を知らない        → 知らない人に言わなければいけないこと
【興味を持つ】 会社を知っている          → 知っている人に言うこと
【比較する】   他社と比較検討している    → 他社と迷っている人に言うこと
```
> 「**知らない人に言わなきゃいけないことと、知っている人に言うことと、他と迷っている人に言うことは、やっぱり違う**」

**具体的な使い方:**
> 「東急リバブルと比較している時の心情に対して、例えばこういうコンテンツを発信しておけば、**こっち（自社）に来てくれるよね**という、逆算したコンテンツ作りをしたい」

## C. 社員アンケートの設計と回し方

### 目的
現在活躍している従業員（＝定着している人）の統計・共通点を取り、そこから逆算してコンテンツを作る。

### 実施要件
| 項目 | 内容 |
|---|---|
| 対象 | **営業職の全社員**（欲しい職種に絞る。全126名のうち営業だけ） |
| 方法 | **Googleフォーム**。制作は自社側、配布はクライアントの人事 |
| 所要時間 | **10〜15分で答えられる** ボリューム |
| 主質問 | 「**なんで入社を決めたんですか**」を軸に、知る→興味→比較の各フェーズを聞く |

### 🔴 匿名性の担保（ここが成否を分ける）
> 「**上辺のアンケートになっちゃうと、結局あまり意味をなさない**」
> 「**社長には見せないし、なんなら誰が書いたか分からないようにもする**。内容だけこちらに置くので、
> **匿名で書けるようにするから、ちょっと本音で書いてほしい**、というのを広めていただけると嬉しい」

### クライアント側の反応（提案が刺さった証拠）
> 「もう**私たち全部最初から打ち出したくなっちゃう**んで、ちょっと是非やらせていただきます」
- 副次効果：アンケートの分析結果が、クライアント社内（役員との議論）で使える資料になる
  > 「アンケートに答えたらこういう分析結果を出してもらえるんですよ、というのを、この後の（役員）との話で出したい」

### 併せて回収するもの
- **SNS経由で応募し、実際に入社した社員のヒアリング内容**（生の一次情報）
- 内定に至った候補者の**面談記録**

## D. 撮影機会としての「社内イベント」の見つけ方

定例イベント（スタート会）が中止になった時に、代わりを探し当てた例：

**「環境整備」の巡回点検**（社長が1日かけて全営業所を回る）
- 各事業所が「定位置決めシート」「やるべきことリスト」を守れているかの定期点検
- 各事業所に**環境整備リーダー**という担当がいる＝**登場人物が最初から決まっている**

### 撮る/撮らないの判断基準（クリエイティブ責任者の発言）
> 「そこで『**もっと会社を良くするために**』という熱量がすごくこもる感じの回で、
> いわゆる**作業的な点検じゃなければいい**なと思っている。**すごい絵になる**と思って」
> 「社長が（僕に対して）『資料が高めで』とはっきり言ってくれるぐらいの温度感で点検を回るんだったら、すごく面白そう」

### 実施判断のGO条件（撮影に行く前に潰すリスク）
1. **タイムスケジュールが確定していること**（8:30開始／16:00頃終了／最後の訪問先次第で変動）
2. 🔴 **各場所で登場人物になる人が、動画に映ってOKか確認が取れていること**
   > 「その人が動画に出れないとなるとややこしくなる。**行ったけど撮れる絵がない**、みたいになっちゃうので、そこだけ確認が取れたらGOという感じでいきたい」
3. 移動手段の確認（撮影班が社長の車に同乗できない場合、各拠点で待機し別移動）
4. 最大の懸念：「**社長が先に着いて（点検を）始めちゃう**のが一番怖い」

### 保険をかける
- クライアント社内に動画編集インターンがいる → 「最悪それをもらう（素材として）」
- 社長に同行するスタッフが車内撮影を担えるか確認しておく

### 撮影機会をこじ開ける小技
> クライアント「最近**社長がテニスを始めまして**」
> クリエイティブ責任者「ちなみに**僕らもテニスやります**。うちの代表もめっちゃテニスを続けてます。だから**呼んでもらったら僕、なんとなくテニスできます**」
→ プライベート接点＝密着コンテンツの機会に変える

## E. 定型の所作
- 「**予定は作りましょう**」（クライアントが「予定が入っていない日が多い」と言った時）
- 会議後に「**議事録と合わせて整理したもの**」を必ず送付する
- 新メンバーは会議で紹介し、経歴で信用を作る（「YouTubeのディレクション・編集をバリバリやってらっしゃる方。**即戦力**でございます」）
- 契約更新は「契約内容は基本的に変わらず、契約期間を前回からの引き続きで」とシンプルに提示する
