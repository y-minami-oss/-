# 利久版 ショートドラマ制作チェックリスト（「オチは、牛タン定食。」用）

元の「バズ・チェックリスト」を、**実在の飲食ブランド＋日常あるある×ほっこりオチ**というトーンに翻訳。
各項目を〇採用／△調整して採用／✕不採用（理由）で仕分け。判断基準は `演出ガイドライン_採用しない演出.md` と一貫：**食べ物を粗末にしない・誤情報を流さない・実在の他者や地域を中傷しない・ブランド信頼を壊さない**。

---

## Ⅰ. 冒頭0〜5秒
| 項目 | 判定 | 利久での使い方 / 理由 |
|---|---|---|
| 視覚的違和感（ノイズ） | 〇 | ただし**食べ物を粗末にしない・不快でない**違和感に。例：スーツで真顔で牛タン定食を拝む／会議中に牛タンの被り物／麦飯の茶碗を9杯並べて仁王立ち。※マヨ過剰投入・自己注射等はやらない |
| 顔と手元のクローズアップ | 〇 | そのまま採用。表情＋定食/箸の接写で掴む |
| フックワード・対立の即時提示 | △ | **軽い日常の葛藤**に置換。「また残業かよ」「デート、店が決まらん」「ダイエット3日目」。※「俺の子ども産んで」等の炎上系は✕ |
| ビジュアル・パラドックス | 〇 | 日常空間に“予想外だが害のない”絵。採用 |
| 不条理の門（搾取・差別・いじめ） | ✕ | 飲食コメディに不要・ブランド毀損。義憤を煽らない |

## Ⅱ. ストーリー・プロット
| 項目 | 判定 | 利久での使い方 / 理由 |
|---|---|---|
| レイジ＆カタルシス（制裁） | ✕→置換 | 怒りでなく「**日常の疲れ・迷い → 牛タン定食で報われる**」カタルシスに変換 |
| 善悪リバース（不倫暴露） | ✕ | 炎上ドラマ。飲食店に不要 |
| フェイク・ハッピーエンド（死/事故） | ✕ | 残酷・ブランド毀損 |
| サイコ・オプティマイズ（犯罪手段） | ✕ | 反社会的。不採用 |
| モラル・ジレンマ | △ | **軽い二択論争**（塩派vsタレ派／厚切りvs薄切り）だけOK。モラル違反系は✕ |
| ベネファクター・パンチ（善人に逆ギレ） | ✕ | 不快・不採用 |
| カウントダウン残酷嘘 | ✕ | 不採用 |
| ソーシャル因果応報（賠償/絶縁） | ✕ | 重すぎ・不採用 |
| サクリファイス（実は陰で支えていた） | △ | **温かい範囲で採用可**：無口な焼き長が実は…等のほっこり反転。重くしない |
| ミスリード（生理周期/若年性認知症を釣りに） | ✕ | 繊細・医療をフック化＝不適切 |
| クリフハンガー/失踪 | △ | シリアスな失踪・退学届は✕。**軽い「続きは次回」**ならOK |
| 認知ループ（矛盾で再視聴） | 〇 | オチの様式で自然に再視聴を促す。採用 |
| 逆算構成（結末先出し→巻き戻し） | △ | **“型”だけ採用**：牛タンを頬張る幸福顔を先に→「なぜこうなった？」→日常ドラマ。復讐の中身は✕ |
| 不条理パラドックス（搾取を美談化） | ✕ | 不採用 |
| 残酷シャドウ（格差対比） | ✕ | 重い格差煽りは不採用 |

## Ⅲ. 演出・映像・音響（ここは大半が有効）
| 項目 | 判定 | 使い方 |
|---|---|---|
| 高速カット割り（1.2〜2.5秒） | 〇 | 日常パートをテンポよく。採用 |
| 色彩で心理/時間を可視化 | 〇 | **牛タンのオチ＝暖色・高彩度**で幸福感、日常パートは少し寒色。採用 |
| 聴覚の引き算（無音→復活） | 〇 | **オチ直前に無音→炭火の「ジュッ」**で最大化。採用 |
| 身体的・小道具アンカー | 〇 | 箸の持ち方・お揃いの小物などで語らせる。採用 |
| ダブル・モノローグ・テロップ | 〇 | 本音テロップ＝あるあるに最適。採用 |

## Ⅳ. 心理ハック＆コメント欄
| 項目 | 判定 | 使い方 / 理由 |
|---|---|---|
| 二者非両立・着火 | △ | **塩vsタレ／厚切りvs薄切り**の軽い論争はOK。人格対立の煽りは✕ |
| サイレント・ベイト（医療器具ラベル等で釣る） | ✕ | 誤情報・不適切。代わりに**安全なツッコミ余白**（黒板のわざと誤字・牛タンの被り物）を1つ |
| ローカル・ディス（実在都市を煽る） | ✕ | 実在地域の中傷。不採用 |
| ロジカル・カタルシス（事実で静かに） | △ | 攻撃的でなければ可（例：産地や職人技を事実で示す） |
| グレー・モラル・トラップ（食べ放題でタン隠す等） | ✕ | 行儀の悪さ×食べ物を粗末＝飲食店には致命的 |
| 一時停止ギミック | △ | 一瞬のテキスト遊びはOK。**隠して巻き戻しを強要しない／年収・退学等のシリアスは✕**。オチは必ず見せる |

## Ⅶ. 最終確認（毎本これを通す）

- [ ] 中盤に小さな展開/迷いがあるか

- [ ] 再視聴を促す仕掛け（様式オチ・ループ）があるか

- [ ] キャプション1行目が視聴者への問いか

- [ ] **【利久・必須】独自資産（炭火の音・肉厚の断面・麦飯・テールスープ）とオチの決め描写＋「牛タンなら、利久」が入っているか**

## まとめ（このシリーズで“採用する型”）
**掴み**＝害のない違和感＋顔/手元の接写／**中身**＝日常あるある＋本音テロップ＋高速カット＋オチ直前の無音／**オチ**＝遅延型で牛タン定食（前半はドラマに集中）＋温かい伏線回収／**締め**＝様式ループ＋問いかけキャプション＋「お近くの利久で」。
炎上・不快・誤情報・中傷の技術は**構造だけ借りて中身は健全に置換**する——これが実在ブランドで長く続けられる作り方。
