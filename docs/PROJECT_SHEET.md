# プロジェクトシート 毎月更新ツール

三並さん担当(SSP)の各クライアントについて、**毎月の数字を自動で集計し、
プロジェクトシートに貼る内容をコピペできる形で出力**するツールです。

## 何ができるか

```
マネジメントシート(全体シート)
   ↓ ① 三並さん担当 × ステータス「アクティブ」の案件を自動抽出(現在16件)
各クライアントの「効果測定シート」→「簡単DC」タブ(TikTokデータが自動で溜まる表)
   ↓ ② 対象月に投稿された行だけを集計
   ↓ ③ プロジェクトシートの「月次の目標と実績」に貼る数字を整形
ターミナルに、クライアントごとのコピペ用ブロックを出力
```

### 自動で出る数字(効果測定シートから)
- **再生数**(再生回数の合計)
- **プロフィール閲覧数**(合計)
- **フォロワー数**(今月の増加数)
- **エンゲージメント率**(=(いいね+コメント+シェア+保存)÷再生回数)
- 参考値: 投稿本数 / リーチ数 / いいね・コメント・シェア・保存

### 手入力が必要な数字(出所が効果測定シートに無いもの)
出力に `▼要手入力` として枠だけ出ます。ここは人が埋めます。
- **KGI:採用数**(商談・入塾・採用などの実績)
- **KPI:リンククリック数**(LINE/計測ツールの数値)
- **LINE登録数**
- **Googleアナリティクス**(セッション/CV 等)

> ℹ️ 「効果測定シートにこの数字も入っている」「この項目も自動化したい」という
> ものがあれば追加できます。`project_sheet/dc.py`(列名)と `report.py`(出力項目)で調整します。

## なぜ「自動入力」ではなく「コピペ出力」か

プロジェクトシートはクライアントごとに別ファイルで、レイアウトも少しずつ違います。
誤った欄に自動で書き込むと事故になるため、**まずは安全に「貼る数字を出す」**ところまでを
自動化しています(TeamSpirit ツールが下書きで止めるのと同じ考え方)。
スプレッドシートへの直接書き込み(自動入力)は次フェーズで、レイアウトを固定できた
クライアントから順に対応できます。

## セットアップ(Mac・初回のみ)

### 1. 依存パッケージ
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Google の読み取り権限(OAuth)を用意
Google スプレッドシートを読むための認証を一度だけ設定します(読み取り専用)。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「Google Sheets API」と「Google Drive API」を有効化
3. 「APIとサービス」→「認証情報」→「OAuth クライアントID」を作成
   - アプリの種類: **デスクトップ アプリ**
4. JSON をダウンロードし、リポジトリ直下に **`credentials.json`** として置く
   (`credentials.json` / `token.json` は `.gitignore` 済み)

### 3. 設定ファイル
```bash
cp project_sheet/config.example.yaml project_sheet/config.yaml
```
`config.yaml` を開き、必要に応じて編集:
- `master_spreadsheet_id` … マネジメントシートのID(既定で設定済み)
- `owner` … 自分の名前(既定:三並)
- `koka_spreadsheet_ids` … クライアント名 → 効果測定シートID の対応表
  - 確実にしたいクライアントはここにIDを書く(URL の `/d/<ID>/edit` 部分)
  - 未登録なら実行時にタイトル検索で探します

## 使い方

```bash
source .venv/bin/activate

# 先月分(既定)を集計して出力
python -m project_sheet.run

# 月を指定
python -m project_sheet.run --month 2026-05

# 特定クライアントだけ(部分一致)
python -m project_sheet.run --client 廣記
```

初回だけブラウザが開いて Google ログインを求められます(以降は `token.json` で自動)。

出力例:
```
### 株式会社廣記商行  (No.72 SSP担当)
対象月: 2026年5月  / 投稿本数: 4本

【月次の目標と実績｜結果欄に貼る数字】
- KGI:採用数            … ▼要手入力(商談・入塾・採用などの実績)
- KPI:リンククリック数   … ▼要手入力(LINE/計測ツールの数値)
- KPI:プロフィール閲覧数 … 6,900
- KPI:フォロワー数      … +172(今月の増加。合計は前月実績+増加)
- KPI:再生数            … 79,621
- KPI:エンゲージメント率 … 1.33%
...
```
この内容を該当クライアントのプロジェクトシートの「結果」欄に貼っていきます。

## テスト(OAuth不要)
```bash
python -m unittest tests.test_project_sheet -v
```
集計ロジック・マスター解析・出力整形を、合成データで検証します。

## ファイル構成
```
project_sheet/
├── dc.py            「簡単DC」タブの列名定義
├── aggregate.py     対象月のKPI集計(純粋ロジック)
├── master.py        全体シート → 担当者のアクティブ案件
├── sources.py       データ取得(gspread / .xlsx)
├── gsheets.py       Google OAuth 接続
├── report.py        コピペ用の出力整形
├── run.py           メイン(CLI)
└── config.example.yaml  設定サンプル
```

## 今後の拡張(相談しながら)
- **自動入力**: レイアウトを固定できたクライアントから、プロジェクトシートへ直接書き込み
- **LINE登録数 / Googleアナリティクス**: API連携で自動取得(現在は手入力枠)
- **対象クライアントの追加**: `koka_spreadsheet_ids` にID追記、または検索キーワード調整
