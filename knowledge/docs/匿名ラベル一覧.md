新しい議事録を追記するときの手順：

1. まずこの表で、同じクライアントの既存ラベルを探す（業種と時期で照合する）
2. あれば **必ずそのラベルを再利用する**
3. なければ「業種＋未使用のアルファベット＋社」で新しい記号を割り当て、この表に行を足す
4. 自社メンバーとクライアント側の個人は、下の表のとおり役割名・役職名にする

記号は「業種＋アルファベット」で一意になる。アルファベットは業種をまたいで再利用してよい
（例：保険代理店G社 と 建設・清掃業H社 は別のクライアント）。
