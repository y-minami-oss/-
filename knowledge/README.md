# 社内ナレッジ抽出

会議ログに溜まっていた商談・打ち合わせの記録を横断し、社内に散っているノウハウを抽出・構造化したものです。

> 🔒 **これは公開版です。**
> このリポジトリは公開設定のため、**クライアント企業名・個人名は業種別の記号に置き換え**（A社／営業担当X など）、
> **自社の原価構造・契約単価の実額、案件ごとの継続角度、入金状況は伏せています**。
> 実額を含む社内版は `PRIVATE/`（リポジトリには含めない）にあります。

## 経緯：tldv.io には直接アクセスできなかった
このセッションのネットワークは組織のエグレスポリシー配下にあり、`tldv.io:443` と `pasta.tldv.io:443`（tldv公式API）は
いずれも **CONNECT 403（policy denial）** で遮断されていました。プロキシの迂回は禁止事項のため実施していません。

代わりに、**社内のGoogle Driveに落ちている二次データ**から抽出しました。結果的にこちらの方が構造化されていました。

## 気づいた構造的な問題（提言）
1. **959商談の資産が動画のまま眠っている。**「全商談をAIに読ませて営業改善」という企画は
   *ダウンロードして格納する*までで止まっており、テキスト化されていない。tldv側にはトランスクリプトがあるはずなので、
   本来は動画ではなく**トランスクリプトを書き出す**べきだった。
2. **振り返りフォーマットは既に優秀。**「率直な感想／気づき・学び／取り入れたいフレーズ2つ（時間付き）」の3列は
   そのままAIへの抽出プロンプトに転用できる。
3. **ナレッジが個人のDriveに閉じている。** Meet Recordings は個人所有。チーム資産化されていない。
4. **同じ論点への回答が人によって違う。** 助成金の適用条件、計測の限界の説明など、
   繰り返し聞かれる質問に対する**会社としての公式回答が文書化されていない**（ノート12・13参照）。
