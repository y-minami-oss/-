## 2. GA4 セットアップ手順（測定IDの発行）

1. [Google Analytics](https://analytics.google.com/) にログイン（管理者アカウント）
2. **管理（歯車）→ プロパティを作成** → プロパティ名「恭子ママ_採用LP」等
3. **データストリーム → ウェブ** を追加 → URL に LP の公開URLを入力
4. 発行された **測定ID（`G-XXXXXXXXXX`）** をコピー
5. `index.html` の `<script id="config">` 内 **`GA_ID`** に貼り付け → 反映完了

> 測定IDを入れるまで、LPは計測タグを読み込みません（誤計測・エラーを防ぐ設計）。

## 3. ユーザーへのアクセス権限 付与手順（GA4）

> ⚠️ 権限付与は **GA管理画面での操作が必須**（API/自動付与は不可）。下記で2〜3分で完了します。

1. GA4 **管理 → プロパティ → プロパティのアクセス管理**
2. 右上 **「＋」→ ユーザーを追加**
3. 上記台帳の3アドレスを入力し、各ロールを選択
   - `y-minami@tre-pro.co.jp` → **管理者**
   - `yuuri.minami@tlpc-t.co.jp` → **編集者**
   - `tsp@tre-pro.co.jp` → **アナリスト**
4. 「新規ユーザーにメールで通知する」にチェック → **追加**

## 4. Drive（効果測定シート／アカウント管理シート）の共有

採用ファネルの「応募〜採用」はLINEログ・効果測定シート側で管理しているため、
同じ3アドレスにDriveの共有も揃えておくと分析が一気通貫になります。

- 対象：`【044_株式会社TOWA/恭子ママ】効果測定シートv3`、`同 アカウント管理シート`
- 手順：各シート右上 **共有** → 3アドレスを追加 → 台帳の「Drive」列のロールを付与

## 5. 計測している主要イベント（LP実装済み）

| イベント名 | 発火タイミング | 用途 |
|---|---|---|
| `page_view` | LP表示 | LP到達数（プロフ閲覧→LP の検証） |
| `line_add_click` | LINE追加ボタン押下（中間/追従） | **主要CV**：LP→LINE 転換率 |
| `dm_click` | TikTok DM導線の押下 | 代替導線の貢献測定 |

- 流入元は `utm_source` 等のユーザープロパティで保持（TikTok動画別の貢献分析が可能）。
- GA4 で `line_add_click` を **キーイベント（コンバージョン）** に設定推奨。

---

## 6. 推奨：見るべきKPI（効果測定シートのファネルと接続）

```
TikTok再生 → プロフ閲覧 → LP到達(page_view) → ★line_add_click → LINE登録 → 応募 → 採用
                                  └─ GA4で計測 ─┘     └──── LINEログ／効果測定シート ────┘
```

- GA4側：**LP到達 → line_add_click 転換率**（導線改善の効果を直接測定）
- シート側：**LINE登録 → 応募 → 採用**（既存の月次管理を継続）
- 両者を突き合わせると、前回特定したボトルネック「プロフ→LINE 0.03%」の改善が定量で追える。
